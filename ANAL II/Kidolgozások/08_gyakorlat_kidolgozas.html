A 8. gyakorlat kidolgozva

Racionális törtfüggvények integrálása: elemi törtek (alaptípusok), maradékos osztás, a nevező szorzattá alakítása és a parciális törtekre bontás. Előbb próbáld meg magad, és csak utána nyisd le a megoldást.

Ami kell hozzá

Emlékeztető

Racionális törtfüggvény: \(\frac{P}{Q}\), ahol \(P\), \(Q \not\equiv 0\) polinomok. Folytonos, így minden olyan nyílt intervallumon van primitív függvénye, ahol \(Q\)-nak nincs zérushelye.

1. alaptípus: \(\frac{1}{(ax+b)^n}\)

\[\int\frac{dx}{ax+b} = \frac{\ln|ax+b|}{a} + c,\] \[\int\frac{dx}{(ax+b)^n} = \frac{(ax+b)^{1-n}}{a(1-n)} + c \quad (n \ge 2).\]

Az abszolút értéket az intervallum alapján „feloldjuk”: pl. \(x \lt \frac73\)-ra \(\ln|3x - 7| = \ln(7 - 3x)\).

2. alaptípus: \(\frac{2ax+b}{ax^2+bx+c}\)

A számláló a nevező deriváltja (\(\frac{f'}{f}\) típus):

\[\int\frac{2ax+b}{ax^2+bx+c}\,dx = \ln|ax^2+bx+c| + C.\]

3. alaptípus: \(\frac{1}{ax^2+bx+c}\), \(b^2 - 4ac \lt 0\)

Teljes négyzetté alakítás: \(ax^2 + bx + c = a(x+\alpha)^2 + \beta\) (\(\beta \gt 0\)), majd lineáris helyettesítés az

\[\int\frac{dx}{1 + x^2} = \arctg x + c\]

alapintegrálba. Hasznos: \(\displaystyle\int\frac{dx}{(x+\alpha)^2 + k^2} = \frac1k\arctg\frac{x+\alpha}{k} + c\).

4. alaptípus: \(\frac{Ax+B}{ax^2+bx+c}\), \(b^2 - 4ac \lt 0\)

A számlálót \(Ax + B = \gamma(2ax + b) + \delta\) alakba írjuk. Így a 2. és a 3. alaptípus lineáris kombinációját kapjuk.

5. alaptípus: \(\frac{Ax+B}{(ax^2+bx+c)^n}\), \(n \ge 2\): rekurziós formulával, ilyet nem oldunk meg.

Az általános eljárás

  1. Maradékos osztás, ha \(\deg P \ge \deg Q\): \(\frac PQ = T + \frac RQ\), ahol \(\deg R \lt \deg Q\) vagy \(R \equiv 0\).
  2. A nevező szorzattá alakítása valós első- és gyök nélküli másodfokú tényezők (hatványainak) szorzatára.
  3. Parciális törtekre bontás határozatlan együtthatókkal: elsőfokú tényezőhöz konstans, másodfokúhoz elsőfokú számláló, és a magasabb kitevőknél minden alacsonyabb kitevő is bekerül.
\[\frac{x+1}{(x-2)^3} = \frac{A_1}{x-2} + \frac{A_2}{(x-2)^2} + \frac{A_3}{(x-2)^3}, \qquad \frac{x^2+3}{(x-1)(x^2+x+1)} = \frac{A_1}{x-1} + \frac{B_1x + C_1}{x^2+x+1}.\]

Az együtthatók meghatározása

Közös nevezőre hozás után a két számláló minden \(x \in \R\)-re egyenlő (a nevező zérushelyeiben is, mert polinomok folytonosak). Két út:

  • (a) Együttható-összehasonlítás: \(x\) hatványai szerint rendezünk, és a megfelelő együtthatók egyenlőségéből lineáris egyenletrendszert kapunk.
  • (b) Behelyettesítés: alkalmas \(x\)-eket (főleg a nevező valós gyökeit) írunk be, így egyszerű egyenleteket kapunk.

A kettő keverhető: a gyököket behelyettesítjük, a maradék együtthatókat pl. a főegyütthatóból vagy \(x = 0\)-ból kapjuk.

8. gyakorlat · Feladatok

Órai feladatok

A megoldások menete a 8. gyakorlati anyag kidolgozását követi. Minden eredményt deriválással ellenőriztünk.

1. (a)8. gyakorlat · órai1. alaptípus
\[\int\frac{dx}{(x - \alpha)^n} \quad \big(x \in (-\infty, \alpha),\ \alpha \in \R,\ n = 1, 2, 3, \dots\big)\]
Megoldás

i) \(n = 1\):

\[\int\frac{dx}{x - \alpha} = \int\frac{(x-\alpha)'}{x - \alpha}\,dx = \ln|x - \alpha| + c = \ln(\alpha - x) + c,\]

mert \(x \lt \alpha\) miatt \(x - \alpha \lt 0\).

ii) \(n \ge 2\): \(f^\alpha f'\) típus:

\[\int (x-\alpha)^{-n}(x-\alpha)'\,dx = \frac{(x-\alpha)^{1-n}}{1-n} + c = \frac{1}{(1-n)(x-\alpha)^{n-1}} + c.\]

Eredmény: \(n = 1\): \(\ln(\alpha - x) + c\); \(n \ge 2\): \(\dfrac{1}{(1-n)(x-\alpha)^{n-1}} + c\quad (x \lt \alpha,\ c \in \R)\)

Részletes magyarázat

Miért két eset? Az \(x^{-1}\) primitív függvénye a logaritmus, minden más \(x^{-n}\) hatványé hatványfüggvény. A \(\frac{x^{\alpha+1}}{\alpha+1}\) képlet \(\alpha = -1\)-re nem értelmes.

Abszolút érték: \((\ln(\alpha - x))' = \frac{-1}{\alpha - x} = \frac{1}{x - \alpha}\). ✓ Az \(n \ge 2\) esetben nincs abszolút érték, mert egész kitevőjű hatvány negatív alapra is értelmes.

1. (b)8. gyakorlat · órai1. alaptípus
\[\int\frac{3}{2x+6}\,dx \quad \big(x \in (-3, +\infty)\big)\]
Megoldás
\[\int\frac{3}{2x + 6}\,dx = \frac32\int\frac{(2x+6)'}{2x+6}\,dx = \frac32\ln|2x+6| + c = \frac32\ln(2x+6) + c,\]

mert \(x \gt -3 \Rightarrow 2x + 6 \gt 0\).

Eredmény: \(\frac32\ln(2x+6) + c\quad (x \gt -3,\ c \in \R)\)

Részletes magyarázat

A szorzó: a számlálóban \(2\)-nek kell állnia (\((2x+6)' = 2\)), ezért \(3 = \frac32\cdot 2\).

Más alak: \(\frac32\ln(2x+6) = \frac32\ln 2 + \frac32\ln(x+3)\), tehát \(\frac32\ln(x+3) + c\) is helyes: a \(\frac32\ln 2\) beolvad a konstansba.

1. (c)8. gyakorlat · órai2. alaptípus
\[\int\frac{x+1}{x^2+2x+5}\,dx \quad (x \in \R)\]
Megoldás

\((x^2 + 2x + 5)' = 2x + 2 = 2(x+1)\), így

\[\int\frac{x+1}{x^2+2x+5}\,dx = \frac12\int\frac{(x^2+2x+5)'}{x^2+2x+5}\,dx = \frac12\ln(x^2+2x+5) + c.\]

Eredmény: \(\frac12\ln(x^2+2x+5) + c\quad (x, c \in \R)\)

Részletes magyarázat

Abszolút érték nélkül: \(x^2 + 2x + 5 = (x+1)^2 + 4 \gt 0\) minden \(x\)-re.

Ellenőrzés: \(\big(\frac12\ln(x^2+2x+5)\big)' = \frac12\cdot\frac{2x+2}{x^2+2x+5} = \frac{x+1}{x^2+2x+5}\). ✓

1. (d)8. gyakorlat · órai4. alaptípus
\[\int\frac{2x+3}{x^2+2x+5}\,dx \quad (x \in \R)\]
Megoldás

A számlálóban kialakítjuk a nevező deriváltját: \(2x + 3 = (2x + 2) + 1\).

\[\int\frac{2x+3}{x^2+2x+5}\,dx = \int\frac{2x+2}{x^2+2x+5}\,dx + \int\frac{dx}{x^2+2x+5}.\]

Az első a 2. alaptípus: \(\ln(x^2+2x+5)\). A második a 3. alaptípus, teljes négyzetté alakítással:

\[\int\frac{dx}{(x+1)^2 + 4} = \frac14\int\frac{dx}{1 + \big(\frac{x+1}{2}\big)^2} = \frac14\cdot\frac{\arctg\frac{x+1}{2}}{1/2} = \frac12\arctg\frac{x+1}{2}.\]

Eredmény: \(\ln(x^2+2x+5) + \frac12\arctg\frac{x+1}{2} + c\quad (x, c \in \R)\)

Részletes magyarázat

Recept a 4. alaptípushoz: (1) számold ki a nevező deriváltját (\(2x+2\)); (2) írd a számlálót \(\gamma\cdot(\text{derivált}) + \delta\) alakba (itt \(\gamma = 1\), \(\delta = 1\)); (3) az első rész \(\gamma\ln(\dots)\), a második teljes négyzettel \(\arctg\).

Teljes négyzet: \(x^2 + 2x + 5 = (x+1)^2 + 4\). A 4-et kiemelve \(4\big(1 + (\frac{x+1}{2})^2\big)\), és a lineáris helyettesítésnél \(\frac{1}{1/2} = 2\)-vel kell szorozni.

Ellenőrzés: \(\big(\frac12\arctg\frac{x+1}{2}\big)' = \frac12\cdot\frac{1/2}{1 + \frac{(x+1)^2}{4}} = \frac{1}{(x+1)^2 + 4}\). ✓

2.8. gyakorlat · óraitétel

Fogalmazzuk meg a parciális törtekre bontás tételét, és gyakoroljuk az ebből adódó integrálási módszert.

Megoldás

Saját megfogalmazás. Az előadásdiák (6. előadás, „További módszerek”) ezt a gyakorlatra hagyják; a gyakorlati anyag szövegesen mondja ki. Lent ennek pontos alakja.

Tétel (parciális törtekre bontás). Legyenek \(P\), \(Q\) valós együtthatós polinomok, \(\deg P \lt \deg Q\), és legyen \(Q\) valós szorzatfelbontása

\[Q(x) = a\,(x - a_1)^{k_1}\cdots(x - a_r)^{k_r}\,(x^2 + p_1x + q_1)^{l_1}\cdots(x^2 + p_sx + q_s)^{l_s},\]

ahol az \(a_i\) valós számok különbözők, a másodfokú tényezők különbözők és \(p_j^2 - 4q_j \lt 0\). Ekkor egyértelműen léteznek olyan \(A_{ik}\), \(B_{jl}\), \(C_{jl}\) valós számok, hogy

\[\frac{P(x)}{Q(x)} = \sum_{i=1}^{r}\sum_{k=1}^{k_i}\frac{A_{ik}}{(x - a_i)^k} + \sum_{j=1}^{s}\sum_{l=1}^{l_j}\frac{B_{jl}\,x + C_{jl}}{(x^2 + p_jx + q_j)^l}.\]

Ha \(\deg P \ge \deg Q\), előbb maradékos osztással leválasztjuk a polinomiális részt: \(\frac PQ = T + \frac RQ\).

Az, hogy minden valós polinom ilyen első- és másodfokú tényezőkre bomlik, az algebra alaptételéből következik.

Részletes magyarázat

Miért elég ez az integráláshoz? A jobb oldali tagok mind az 1–5. alaptípusba esnek, és ezeket ki tudjuk integrálni. Így elvben minden racionális törtfüggvény primitív függvénye elemi függvényekkel felírható: \(\ln\), \(\arctg\) és racionális függvények kombinációja.

Hol akad el a gyakorlatban? A 2. lépésnél: ötöd- vagy magasabb fokú polinom gyökeire nincs megoldóképlet, így a szorzattá alakítás csak „elvben” létezik.

Hány ismeretlen? Pontosan \(\deg Q\) darab: az elsőfokú tényezőnként \(k_i\) darab \(A\), a másodfokúaknál \(2l_j\) darab \(B\), \(C\). Ez annyi, ahány egyenletet az együttható-összehasonlítás ad.

2. (a)8. gyakorlat · óraikét valós gyök
\[\int\frac{dx}{x^2 - 6x + 8} \quad \big(x \in (2, 4)\big)\]
Megoldás

\(x^2 - 6x + 8 = 0 \iff x_{1,2} = \frac{6 \pm \sqrt{36 - 32}}{2}\), azaz \(x_1 = 4\), \(x_2 = 2\), így \(x^2 - 6x + 8 = (x-2)(x-4)\).

\[\frac{1}{(x-2)(x-4)} = \frac{A}{x-2} + \frac{B}{x-4} \quad\Longrightarrow\quad 1 = A(x-4) + B(x-2).\]

\(x = 2\): \(1 = -2A \Rightarrow A = -\frac12\). \(x = 4\): \(1 = 2B \Rightarrow B = \frac12\).

Ha \(2 \lt x \lt 4\), akkor \(x - 2 \gt 0\) és \(x - 4 \lt 0\), így

\[\int\frac{dx}{(x-2)(x-4)} = -\frac12\ln(x-2) + \frac12\ln(4-x) + c = \frac12\ln\frac{4-x}{x-2} + c = \ln\sqrt{\frac{4-x}{x-2}} + c.\]

Eredmény: \(\ln\sqrt{\dfrac{4-x}{x-2}} + c\quad \big(x \in (2,4),\ c \in \R\big)\)

Részletes magyarázat

Együttható-összehasonlítással is megy: \(1 = (A + B)x - 4A - 2B\), tehát \(A + B = 0\) és \(-4A - 2B = 1\), ahonnan \(-2A = 1\), \(A = -\frac12\), \(B = \frac12\).

Az intervallum szerepe: \(\ln|x - 4| = \ln(4 - x)\), mert \(x \lt 4\). Egy másik intervallumon (pl. \(x \gt 4\)) a végeredmény \(\frac12\ln\frac{x-4}{x-2}\) lenne.

A grafikon: \((2,4)\)-en \(f \lt 0\), ezért \(F\) szigorúan fogy; az \(x = 3\)-ban \(F(3) = 0\), és a két végpontban \(F \to \pm\infty\).

2. (b)8. gyakorlat · óraikétszeres gyök
\[\int\frac{3x - 5}{x^2 + 2x + 1}\,dx \quad \big(x \in (-1, +\infty)\big)\]
Megoldás

\(x^2 + 2x + 1 = (x+1)^2\), így

\[\frac{3x-5}{(x+1)^2} = \frac{A}{x+1} + \frac{B}{(x+1)^2} \quad\Longrightarrow\quad 3x - 5 = A(x+1) + B.\]

\(x = -1\): \(-8 = B\). \(x = 0\): \(-5 = A + B \Rightarrow A = 3\).

\[\int\Big(\frac{3}{x+1} - \frac{8}{(x+1)^2}\Big)\,dx = 3\ln(x+1) + \frac{8}{x+1} + c.\]

Eredmény: \(3\ln(x+1) + \dfrac{8}{x+1} + c\quad (x \gt -1,\ c \in \R)\)

Részletes magyarázat

Kétszeres gyöknél mindkét kitevő kell: \(\frac{A}{x+1}\) és \(\frac{B}{(x+1)^2}\). Csak \(\frac{B}{(x+1)^2}\)-tel nem lehetne előállítani a számláló \(x\)-es tagját.

Gyorsabban: \(3x - 5 = 3(x+1) - 8\), és ebből rögtön \(\frac{3}{x+1} - \frac{8}{(x+1)^2}\).

Előjel: \(\int -8(x+1)^{-2}\,dx = -8\cdot\frac{(x+1)^{-1}}{-1} = \frac{8}{x+1}\).

2. (c)8. gyakorlat · óraimaradékos osztás
\[\int\frac{x^3 + x^2 - x + 3}{x^2 - 1}\,dx \quad \big(x \in (-1, 1)\big)\]
Megoldás

A számláló foka nagyobb, ezért előbb maradékos osztás:

\[\frac{x^3 + x^2 - x + 3}{x^2-1} = \frac{x(x^2-1) + (x^2-1) + 4}{x^2-1} = x + 1 + \frac{4}{x^2-1}.\]

Parciális törtek: \(\frac{4}{(x-1)(x+1)} = \frac{A}{x-1} + \frac{B}{x+1}\), \(4 = A(x+1) + B(x-1)\). \(x = 1\): \(A = 2\); \(x = -1\): \(B = -2\).

Ha \(-1 \lt x \lt 1\), akkor \(x - 1 \lt 0\) és \(x + 1 \gt 0\), így

\[\int\Big(x + 1 + \frac{2}{x-1} - \frac{2}{x+1}\Big)\,dx = \frac{x^2}{2} + x + 2\ln(1-x) - 2\ln(x+1) + c.\]

Eredmény: \(\dfrac{x^2}{2} + x + \ln\Big(\dfrac{1-x}{x+1}\Big)^2 + c\quad \big(x \in (-1,1),\ c \in \R\big)\)

Részletes magyarázat

Az osztás „ügyesen”: \(x^3 - x = x(x^2-1)\) és \(x^2 + 3 = (x^2 - 1) + 4\). Polinomosztással ugyanez jön: hányados \(x + 1\), maradék \(4\).

Logaritmusok összevonása: \(2\ln(1-x) - 2\ln(x+1) = 2\ln\frac{1-x}{x+1} = \ln\big(\frac{1-x}{x+1}\big)^2\).

Ellenőrzés: \(\big(2\ln(1-x)\big)' = \frac{-2}{1-x} = \frac{2}{x-1}\). ✓

2. (d)8. gyakorlat · óraigyök nélküli másodfokú tényező
\[\int\frac{dx}{x^3 + 4x} \quad \big(x \in (0, +\infty)\big)\]
Megoldás

\(x^3 + 4x = x(x^2+4)\), és \(x^2 + 4\)-nek nincs valós gyöke, ezért

\[\frac{1}{x(x^2+4)} = \frac Ax + \frac{Bx + C}{x^2+4} \quad\Longrightarrow\quad 1 = (A + B)x^2 + Cx + 4A.\]

Együtthatók: \(A + B = 0\), \(C = 0\), \(4A = 1\), azaz \(A = \frac14\), \(B = -\frac14\), \(C = 0\).

Ha \(x \gt 0\):

\[\int\Big(\frac{1}{4x} - \frac14\cdot\frac{x}{x^2+4}\Big)\,dx = \frac14\ln x - \frac18\int\frac{2x}{x^2+4}\,dx = \frac14\ln x - \frac18\ln(x^2+4) + c.\]

Eredmény: \(\frac14\ln x - \frac18\ln(x^2+4) + c = \ln\sqrt[8]{\dfrac{x^2}{x^2+4}} + c\quad (x \gt 0,\ c \in \R)\)

Részletes magyarázat

Másodfokú tényező, elsőfokú számláló: \(\frac{Bx + C}{x^2+4}\), nem csak \(\frac{B}{x^2+4}\). Itt véletlenül \(C = 0\) jött ki, ezért nem lett \(\arctg\)-es tag.

Összevonás: \(\frac14\ln x - \frac18\ln(x^2+4) = \frac18\big(\ln x^2 - \ln(x^2+4)\big) = \frac18\ln\frac{x^2}{x^2+4}\).

Ellenőrzés: \(\big(\frac14\ln x - \frac18\ln(x^2+4)\big)' = \frac{1}{4x} - \frac{x}{4(x^2+4)} = \frac{x^2 + 4 - x^2}{4x(x^2+4)} = \frac{1}{x(x^2+4)}\). ✓

2. (e)8. gyakorlat · óraikétszeres gyök + másodfokú
\[\int\frac{x^3 + 9x - 9}{x^4 + 9x^2}\,dx \quad \big(x \in (0, +\infty)\big)\]
Megoldás

\(x^4 + 9x^2 = x^2(x^2 + 9)\), így

\[\frac{x^3 + 9x - 9}{x^2(x^2+9)} = \frac Ax + \frac{B}{x^2} + \frac{Cx + D}{x^2 + 9}.\]

Közös nevezőre hozva: \(x^3 + 9x - 9 = (A + C)x^3 + (B + D)x^2 + 9Ax + 9B\). Együtthatók:

\[A + C = 1,\quad B + D = 0,\quad 9A = 9,\quad 9B = -9 \;\Longrightarrow\; A = 1,\ B = -1,\ C = 0,\ D = 1.\]

Ha \(x \gt 0\):

\[\int\Big(\frac1x - \frac{1}{x^2} + \frac{1}{x^2+9}\Big)\,dx = \ln x + \frac1x + \frac19\int\frac{dx}{1 + (\frac x3)^2} = \ln x + \frac1x + \frac13\arctg\frac x3 + c.\]

Eredmény: \(\ln x + \dfrac1x + \dfrac13\arctg\dfrac x3 + c\quad (x \gt 0,\ c \in \R)\)

Részletes magyarázat

A felbontás alakja: az \(x^2\) kétszeres gyök (\(x = 0\)), tehát \(\frac Ax\) és \(\frac{B}{x^2}\) is kell; az \(x^2 + 9\) gyök nélküli, ehhez \(\frac{Cx+D}{x^2+9}\). Összesen 4 ismeretlen, a nevező is negyedfokú.

Gyors behelyettesítés: \(x = 0\)-t beírva a számlálók egyenlőségébe: \(-9 = 9B\), tehát \(B = -1\) azonnal.

Az arctg-es tag: \(\int\frac{dx}{x^2 + 3^2} = \frac13\arctg\frac x3\) (a hasznos képlet \(k = 3\)-mal).

8. gyakorlat · Házi feladatok · saját megoldás

Házi feladatok

Az összevont gyakorlati anyag 8. gyakorlathoz tartozó házi feladatai. Ezekhez nincs hivatalos megoldás, ezek saját megoldások (deriválással ellenőrizve).

1. (a)8. gyakorlat · házikét valós gyök
\[\int\frac{7x + 5}{x^2 + 2x - 3}\,dx \quad \big(x \in (-3, 1)\big)\]
Megoldás

\(x^2 + 2x - 3 = (x - 1)(x + 3)\) (gyökök: \(1\) és \(-3\)).

\[\frac{7x + 5}{(x-1)(x+3)} = \frac{A}{x-1} + \frac{B}{x+3} \quad\Longrightarrow\quad 7x + 5 = A(x+3) + B(x-1).\]

\(x = 1\): \(12 = 4A \Rightarrow A = 3\). \(x = -3\): \(-16 = -4B \Rightarrow B = 4\).

Ha \(-3 \lt x \lt 1\), akkor \(x - 1 \lt 0\) és \(x + 3 \gt 0\), így

\[\int\Big(\frac{3}{x-1} + \frac{4}{x+3}\Big)\,dx = 3\ln(1 - x) + 4\ln(x + 3) + c.\]

Eredmény: \(3\ln(1-x) + 4\ln(x+3) + c\quad \big(x \in (-3,1),\ c \in \R\big)\)

Részletes magyarázat

Ellenőrzés összeadással: \(\frac{3}{x-1} + \frac{4}{x+3} = \frac{3(x+3) + 4(x-1)}{(x-1)(x+3)} = \frac{7x + 5}{x^2+2x-3}\). ✓

Előjel: \(\big(3\ln(1-x)\big)' = \frac{-3}{1-x} = \frac{3}{x-1}\). ✓

1. (b)8. gyakorlat · házi4. alaptípus
\[\int\frac{2 - x}{x^2 - 2x + 10}\,dx \quad (x \in \R)\]
Megoldás

A nevező diszkriminánsa \(4 - 40 \lt 0\), és \((x^2 - 2x + 10)' = 2x - 2\). A számlálót ennek segítségével írjuk fel:

\[2 - x = -\frac12(2x - 2) + 1.\] \[\int\frac{2-x}{x^2-2x+10}\,dx = -\frac12\int\frac{2x-2}{x^2-2x+10}\,dx + \int\frac{dx}{(x-1)^2 + 9}\] \[= -\frac12\ln(x^2 - 2x + 10) + \frac13\arctg\frac{x-1}{3} + c.\]

Eredmény: \(-\frac12\ln(x^2-2x+10) + \frac13\arctg\frac{x-1}{3} + c\quad (x, c \in \R)\)

Részletes magyarázat

\(\gamma\) és \(\delta\) keresése: \(2 - x = \gamma(2x - 2) + \delta\). Az \(x\)-es tagból \(2\gamma = -1\), azaz \(\gamma = -\frac12\); a konstansból \(-2\gamma + \delta = 2\), azaz \(\delta = 1\).

Teljes négyzet: \(x^2 - 2x + 10 = (x-1)^2 + 9 = (x-1)^2 + 3^2\), és \(\int\frac{dx}{(x-1)^2 + 3^2} = \frac13\arctg\frac{x-1}{3}\).

Ellenőrzés: \(\Big(-\frac12\ln(\dots) + \frac13\arctg\frac{x-1}{3}\Big)' = \frac{-(x-1)}{x^2-2x+10} + \frac{1}{(x-1)^2 + 9} = \frac{-x + 1 + 1}{x^2-2x+10}\). ✓

1. (c)8. gyakorlat · háziosztás + parciális törtek
\[\int\frac{x^3 - 4}{x^3 + x}\,dx \quad (x \gt 0)\]
Megoldás

A fokszámok egyenlők, ezért előbb leválasztjuk a polinomiális részt:

\[\frac{x^3 - 4}{x^3 + x} = \frac{(x^3 + x) - x - 4}{x^3 + x} = 1 - \frac{x + 4}{x(x^2 + 1)}.\]

Parciális törtek:

\[\frac{x + 4}{x(x^2+1)} = \frac Ax + \frac{Bx + C}{x^2+1} \;\Longrightarrow\; x + 4 = (A + B)x^2 + Cx + A,\]

tehát \(A = 4\), \(C = 1\), \(B = -4\). Így

\[\frac{x^3-4}{x^3+x} = 1 - \frac4x + \frac{4x - 1}{x^2 + 1} = 1 - \frac4x + 2\cdot\frac{2x}{x^2+1} - \frac{1}{x^2+1}.\]

Ha \(x \gt 0\):

\[\int\frac{x^3-4}{x^3+x}\,dx = x - 4\ln x + 2\ln(x^2 + 1) - \arctg x + c.\]

Eredmény: \(x - 4\ln x + 2\ln(x^2+1) - \arctg x + c\quad (x \gt 0,\ c \in \R)\)

Részletes magyarázat

Lépések: (1) \(\deg P = \deg Q = 3\), tehát osztani kell (hányados 1, maradék \(-x - 4\)); (2) \(x^3 + x = x(x^2+1)\), az \(x^2+1\) gyök nélküli; (3) felbontás \(\frac Ax + \frac{Bx+C}{x^2+1}\) alakban.

Előjel figyelés: \(-\frac{x+4}{x(x^2+1)} = -\big(\frac4x + \frac{-4x + 1}{x^2+1}\big) = -\frac4x + \frac{4x - 1}{x^2+1}\).

A \(\frac{4x-1}{x^2+1}\) tag a 4. alaptípus: \(4x = 2\cdot(x^2+1)'\), és a \(-1\) rész \(\arctg\)-et ad.

Ugyanez a gyakorló feladatok között is szerepel (1. (k)).

Mire figyelj

Gyakori hibák

✕

Kimaradt maradékos osztás. Ha \(\deg P \ge \deg Q\), a parciális törtekre bontás nem működik közvetlenül: előbb le kell választani a polinomiális részt (órai 2(c), házi 1(c)).

✕

Hiányzó alacsonyabb kitevő. \((x+1)^2\) a nevezőben: \(\frac{A}{x+1} + \frac{B}{(x+1)^2}\) kell, nem csak a második tag (órai 2(b)).

✕

Konstans számláló a másodfokú tényező fölött. Gyök nélküli másodfokú tényezőhöz \(Bx + C\) tartozik, nem \(B\) (órai 2(d)).

✕

Abszolút érték az intervallum figyelembe vétele nélkül. \(\int\frac{dx}{x-1} = \ln|x-1|\), és ha \(x \lt 1\), akkor ez \(\ln(1-x)\), nem \(\ln(x-1)\) (ez ott nem is értelmes).

✕

Hibás arctg-szorzó. \(\int\frac{dx}{(x+\alpha)^2 + k^2} = \frac1k\arctg\frac{x+\alpha}{k}\). A \(\frac1k\) és a \(\frac{1}{k^2}\) gyakran összekeveredik.

✕

Szorzattá alakítás valós gyökkel rendelkező másodfokú tényezővel. Ha \(b^2 - 4ac \ge 0\), a másodfokú tényezőt tovább kell bontani elsőfokúakra (pl. \(x^2 - 6x + 8 = (x-2)(x-4)\)).
