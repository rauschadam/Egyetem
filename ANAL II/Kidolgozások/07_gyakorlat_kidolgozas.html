Primitív függvény, határozatlan integrál

Legyen \(I \subset \R\) nyílt intervallum, \(f : I \to \R\). Az \(F : I \to \R\) az \(f\) primitív függvénye, ha \(F \in D(I)\) és \(F'(x) = f(x)\) \((x \in I)\).

Intervallumon bármely két primitív függvény csak konstansban tér el, ezért

\[\int f(x)\,dx = F(x) + c \quad (x \in I).\]

Az intervallumot mindig fel kell tüntetni. Ellenőrzés: \(F' = f\)?

Linearitás

Ha \(f\)-nek és \(g\)-nek van primitív függvénye \(I\)-n, akkor minden \(\alpha, \beta \in \R\)-re

\[\int (\alpha f + \beta g) = \alpha\int f + \beta\int g.\]

Szorzatra és hányadosra nincs ilyen szabály: \(\int fg \ne \int f \cdot \int g\).

Alapintegrálok

\(f(x)\)\(\int f(x)\,dx\)\(f(x)\)\(\int f(x)\,dx\)
\(x^\alpha\) \((\alpha \ne -1)\)\(\dfrac{x^{\alpha+1}}{\alpha+1}\)\(\dfrac{1}{\cos^2 x}\)\(\tg x\)
\(\dfrac1x\) \((x \gt 0)\)\(\ln x\)\(\dfrac{1}{\sin^2 x}\)\(-\ctg x\)
\(e^x\)\(e^x\)\(\dfrac{1}{1+x^2}\)\(\arctg x\)
\(a^x\) \((a \gt 0, a \ne 1)\)\(\dfrac{a^x}{\ln a}\)\(\dfrac{1}{\sqrt{1-x^2}}\) \((|x| \lt 1)\)\(\arcsin x\)
\(\sin x\)\(-\cos x\)\(\operatorname{sh} x\)\(\operatorname{ch} x\)
\(\cos x\)\(\sin x\)\(\operatorname{ch} x\)\(\operatorname{sh} x\)

Első helyettesítési szabály és speciális esetei

Ha \(g \in D(I)\), \(\mathcal R_g \subset J\) és \(F\) az \(f : J \to \R\) primitív függvénye, akkor

\[\int f\big(g(x)\big)\,g'(x)\,dx = F\big(g(x)\big) + c \quad (x \in I).\]
  • \(\frac{f'}{f}\) típus (\(f \gt 0\)): \(\displaystyle\int \frac{f'(x)}{f(x)}\,dx = \ln f(x) + c\). Ha \(f \lt 0\), akkor \(\ln(-f(x)) + c\).
  • \(f^\alpha f'\) típus (\(f \gt 0\), \(\alpha \ne -1\)): \(\displaystyle\int f^\alpha(x)\,f'(x)\,dx = \frac{f^{\alpha+1}(x)}{\alpha+1} + c\). Ha \(\alpha \in \mathbb N\), az \(f \gt 0\) feltétel nem kell.
  • Lineáris helyettesítés (\(a \ne 0\)): \(\displaystyle\int f(ax+b)\,dx = \frac{F(ax+b)}{a} + c\).

Parciális integrálás

Ha \(f, g \in D(I)\) és \(f'g\)-nek van primitív függvénye, akkor

\[\int f g' = f g - \int f' g.\]

Szereposztás: \(P(x)\cdot\{e^{ax}, \sin, \cos\}\): \(f = P\). \(P(x)\cdot\{\ln, \operatorname{arc}\dots\}\): \(g' = P\). \(\int \ln x\), \(\int \arctg x\): \(g' = 1\).

Hasznos trigonometrikus azonosságok

  • \(\sin^2 x = \dfrac{1 - \cos 2x}{2}\), \(\cos^2 x = \dfrac{1 + \cos 2x}{2}\)
  • \(1 + \cos 2x = 2\cos^2 x\)
  • \(\sin^2 x + \cos^2 x = 1\), tehát \(\sin^3 x = (1 - \cos^2 x)\sin x\)
  • \((\tg x)' = \dfrac{1}{\cos^2 x}\)
7. gyakorlat · Feladatok

Órai feladatok

A megoldások menete a 7. gyakorlati anyag kidolgozását követi. Minden eredményt deriválással ellenőriztünk.

1. (a)7. gyakorlat · órailinearitás

Határozzuk meg az \(f(x) := 6x^2 - 8x + 3\) \((x \in \R)\) függvény határozatlan integrálját.

Megoldás
\[\int (6x^2 - 8x + 3)\,dx = 6\int x^2\,dx - 8\int x\,dx + 3\int 1\,dx = 6\cdot\frac{x^3}{3} - 8\cdot\frac{x^2}{2} + 3x + c\]

Eredmény: \(2x^3 - 4x^2 + 3x + c\quad (x, c \in \R)\)

Részletes magyarázat

Mit használunk? A linearitás miatt tagonként integrálhatunk, a konstans szorzókat kiemelhetjük. Minden tag \(x^\alpha\) alakú alapintegrál (\(1 = x^0\)).

Ellenőrzés: \((2x^3 - 4x^2 + 3x)' = 6x^2 - 8x + 3\). ✓

Elég egyetlen \(+c\)-t írni a végén: a tagonkénti konstansok összege is csak egy tetszőleges konstans.

1. (b)7. gyakorlat · óraiátalakítás · arctg

Határozzuk meg az \(f(x) := \dfrac{x^2}{x^2 + 1}\) \((x \in \R)\) függvény határozatlan integrálját.

Megoldás

A számlálóban kialakítjuk a nevezőt:

\[\int \frac{x^2}{x^2+1}\,dx = \int \frac{x^2 + 1 - 1}{x^2+1}\,dx = \int \Big(1 - \frac{1}{1+x^2}\Big)\,dx = x - \arctg x + c.\]

Eredmény: \(x - \arctg x + c\quad (x, c \in \R)\)

Részletes magyarázat

Az ötlet: „hozzáadunk és elveszünk” 1-et a számlálóban. Így a tört egy polinom (itt: 1) és egy alapintegrál különbsége lesz. Ez a racionális törtek maradékos osztásának gyors változata (lásd 8. gyakorlat).

Ellenőrzés: \(\big(x - \arctg x\big)' = 1 - \frac{1}{1+x^2} = \frac{x^2}{1+x^2}\). ✓

A grafikon: a primitív függvények egymás eltoltjai függőlegesen. Ahol \(f = 0\) (az \(x = 0\) pontban), ott minden \(F + c\) érintője vízszintes, és mivel \(f \ge 0\), mindegyik monoton nő.

1. (c)7. gyakorlat · óraihatványozás

Határozzuk meg az \(f(x) := \sqrt{x\sqrt{x\sqrt{x}}}\) \(\big(x \in (0, +\infty)\big)\) függvény határozatlan integrálját.

Megoldás

Belülről kifelé törtkitevős hatványokra írjuk át:

\[\sqrt{x\sqrt{x\sqrt x}} = \Big(x\big(x \cdot x^{1/2}\big)^{1/2}\Big)^{1/2} = \Big(x \cdot x^{3/4}\Big)^{1/2} = \big(x^{7/4}\big)^{1/2} = x^{7/8}.\] \[\int x^{7/8}\,dx = \frac{x^{7/8 + 1}}{7/8 + 1} + c = \frac{8}{15}\,x^{15/8} + c.\]

Eredmény: \(\frac{8}{15}\sqrt[8]{x^{15}} + c\quad \big(x \in (0,+\infty),\ c \in \R\big)\)

Részletes magyarázat

Lépésenként: \(x\sqrt x = x^{3/2}\), ennek gyöke \(x^{3/4}\); \(x\cdot x^{3/4} = x^{7/4}\), ennek gyöke \(x^{7/8}\). Szorzásnál a kitevők összeadódnak, gyökvonásnál feleződnek.

Ellenőrzés: \(\big(\frac{8}{15}x^{15/8}\big)' = \frac{8}{15}\cdot\frac{15}{8}x^{7/8} = x^{7/8}\). ✓

1. (d)7. gyakorlat · óraitrigonometria

Határozzuk meg az \(f(x) := \dfrac{\cos^2 x - 5}{1 + \cos 2x}\) \(\big(x \in (-\frac\pi2, \frac\pi2)\big)\) függvény határozatlan integrálját.

Megoldás

\(1 + \cos 2x = \sin^2 x + \cos^2 x + \cos^2 x - \sin^2 x = 2\cos^2 x\), így

\[\int \frac{\cos^2 x - 5}{2\cos^2 x}\,dx = \int \Big(\frac12 - \frac52\cdot\frac{1}{\cos^2 x}\Big)\,dx = \frac12\,x - \frac52\,\tg x + c.\]

Eredmény: \(\frac{x}{2} - \frac52\tg x + c\quad \big(|x| \lt \frac\pi2,\ c \in \R\big)\)

Részletes magyarázat

Miért ez az intervallum? A nevező \(2\cos^2 x\) a \(\pm\frac\pi2\)-ben nulla, és a \(\tg\) is csak a \((-\frac\pi2, \frac\pi2)\) intervallumon (és eltoltjain) deriválható. Egy intervallumon dolgozunk, így egyetlen \(+c\) elég.

Ellenőrzés: \(\big(\frac x2 - \frac52\tg x\big)' = \frac12 - \frac{5}{2\cos^2 x} = \frac{\cos^2 x - 5}{2\cos^2 x}\). ✓

2. (a)7. gyakorlat · órai\(\frac{f'}{f}\) típus
\[\int \frac{2x}{x^2 + 3}\,dx \quad (x \in \R)\]
Megoldás
\[\int \frac{2x}{x^2+3}\,dx = \int \frac{(x^2+3)'}{x^2+3}\,dx = \ln(x^2 + 3) + c.\]

Eredmény: \(\ln(x^2+3) + c\quad (x, c \in \R)\)

Részletes magyarázat

Felismerés: a számláló pontosan a nevező deriváltja. Mivel \(x^2 + 3 \gt 0\) minden \(x\)-re, abszolút érték nélkül írhatjuk a logaritmust.

Ellenőrzés: \(\big(\ln(x^2+3)\big)' = \frac{2x}{x^2+3}\). ✓

2. (b)7. gyakorlat · órai\(f^\alpha f'\) típus
\[\int \sin^3 x\cdot\cos x\,dx \quad (x \in \R)\]
Megoldás
\[\int \sin^3 x\cdot(\sin x)'\,dx = \frac{\sin^4 x}{4} + c.\]

Eredmény: \(\frac{\sin^4 x}{4} + c\quad (x, c \in \R)\)

Részletes magyarázat

Felismerés: \(f = \sin\), \(f' = \cos\), \(\alpha = 3\). Mivel \(\alpha \in \mathbb N\), nem kell \(f \gt 0\), tehát az egész \(\R\)-en érvényes.

Ellenőrzés: \(\big(\frac{\sin^4 x}{4}\big)' = \sin^3 x\cos x\). ✓

2. (c)7. gyakorlat · órai\(\frac{f'}{f}\) típus
\[\int \frac{dx}{x\ln x} \quad \big(x \in (1, +\infty)\big)\]
Megoldás

Ha \(x \gt 1\), akkor \(\ln x \gt 0\), és

\[\int \frac{1/x}{\ln x}\,dx = \int \frac{(\ln x)'}{\ln x}\,dx = \ln(\ln x) + c.\]

Eredmény: \(\ln(\ln x) + c\quad (x \gt 1,\ c \in \R)\)

Részletes magyarázat

Miért fontos az intervallum? Az \(\frac{f'}{f}\) képletben \(\ln f\) csak \(f \gt 0\) esetén értelmes. Itt \(f = \ln x \gt 0\), mert \(x \gt 1\).

Ha \(x \in (0,1)\) lenne: ekkor \(\ln x \lt 0\), és \(\int\frac{dx}{x\ln x} = \ln(-\ln x) + c\). Ellenőrzés: \(\big(\ln(-\ln x)\big)' = \frac{-1/x}{-\ln x} = \frac{1}{x\ln x}\). ✓

2. (d)7. gyakorlat · órai\(f^\alpha f'\) típus
\[\int \sin^3 x\cdot\cos^4 x\,dx \quad (x \in \R)\]
Megoldás

\(\sin^3 x = (1 - \cos^2 x)\sin x\) és \(\sin x = -(\cos x)'\) alapján

\[\int \sin^3 x\cos^4 x\,dx = \int (\cos^4 x - \cos^6 x)\sin x\,dx = \int \big(\cos^6 x\cdot(\cos x)' - \cos^4 x\cdot(\cos x)'\big)\,dx\] \[= \frac{\cos^7 x}{7} - \frac{\cos^5 x}{5} + c.\]

Eredmény: \(\frac{\cos^7 x}{7} - \frac{\cos^5 x}{5} + c\quad (x, c \in \R)\)

Részletes magyarázat

Az ötlet: a páratlan kitevőjű tényezőből (\(\sin^3\)) leválasztunk egyet (\(\sin x\)), ez lesz a \(-(\cos x)'\). A maradék \(\sin^2 x\)-et \(1 - \cos^2 x\)-szel kifejezve minden tag \(\cos^n x\cdot(\cos x)'\) alakú.

Előjel: \(\sin x = -(\cos x)'\), ezért \(\cos^4 x\sin x = -\cos^4 x(\cos x)'\), és \(-\cos^6 x\sin x = +\cos^6 x(\cos x)'\).

Ellenőrzés: \(\big(\frac{\cos^7 x}{7} - \frac{\cos^5 x}{5}\big)' = -\cos^6 x\sin x + \cos^4 x\sin x = \cos^4 x\sin x(1 - \cos^2 x) = \sin^3 x\cos^4 x\). ✓

2. (e)7. gyakorlat · órailinearizálás
\[\int \sin^2 x\,dx \quad (x \in \R)\]
Megoldás
\[\int \sin^2 x\,dx = \int \frac{1 - \cos 2x}{2}\,dx = \frac x2 - \frac12\int\cos 2x\,dx = \frac x2 - \frac12\cdot\frac{\sin 2x}{2} + c.\]

Eredmény: \(\frac x2 - \frac{\sin 2x}{4} + c\quad (x, c \in \R)\)

Részletes magyarázat

Miért nem \(\frac{\sin^3 x}{3}\)? Mert az \(f^\alpha f'\) típushoz kellene egy \(\cos x\) szorzó is. Páros kitevőnél a linearizáló formulát használjuk.

Lineáris helyettesítés: \(\int \cos 2x\,dx = \frac{\sin 2x}{2}\): az \(ax + b\) belső függvény miatt \(\frac1a\)-val szorzunk.

Ellenőrzés: \(\big(\frac x2 - \frac{\sin 2x}{4}\big)' = \frac12 - \frac{\cos 2x}{2} = \sin^2 x\). ✓

2. (f)7. gyakorlat · órai\(f^\alpha f'\) típus
\[\int \frac{1}{\cos^2 x\cdot\sqrt{\tg^3 x}}\,dx \quad \big(x \in (0, \tfrac\pi2)\big)\]
Megoldás

Ha \(x \in (0, \frac\pi2)\), akkor \(\cos x \gt 0\) és \(\tg x \gt 0\), ezért

\[\int (\tg x)^{-3/2}\cdot\frac{1}{\cos^2 x}\,dx = \int (\tg x)^{-3/2}(\tg x)'\,dx = \frac{(\tg x)^{-1/2}}{-1/2} + c = -\frac{2}{\sqrt{\tg x}} + c.\]

Eredmény: \(-\dfrac{2}{\sqrt{\tg x}} + c\quad \big(x \in (0,\tfrac\pi2),\ c \in \R\big)\)

Részletes magyarázat

Felismerés: \(\frac{1}{\cos^2 x} = (\tg x)'\), a maradék \(\tg x\) hatványa: \(f = \tg\), \(\alpha = -\frac32\). Mivel \(\alpha \notin \mathbb N\), szükség van az \(f \gt 0\) feltételre, ezt az intervallum biztosítja.

Ellenőrzés: \(\big(-2(\tg x)^{-1/2}\big)' = -2\cdot(-\tfrac12)(\tg x)^{-3/2}\cdot\frac{1}{\cos^2 x} = \frac{1}{\cos^2 x\sqrt{\tg^3 x}}\). ✓

3. (a)7. gyakorlat · óraiparciális integrálás ×2
\[\int (x^2 + 2x - 1)\,e^{-2x}\,dx \quad (x \in \R)\]

Megjegyzés a forráshoz. A gyakorlati anyagban a feladat \(e^{-2x}\)-szel van kitűzve, de a megoldás végig \(e^{2x}\)-szel számol. Az összevont anyagban pedig \(e^{-3x}\) szerepel. Lent a kitűzött \(e^{-2x}\)-es változat van kidolgozva, a másik kettő eredménye a magyarázatban.

Megoldás

Kétszer integrálunk parciálisan, mindkétszer az exponenciális rész a \(g'\): \(e^{-2x} = \big(-\frac{e^{-2x}}{2}\big)'\).

\[\int (x^2+2x-1)e^{-2x}\,dx = -(x^2+2x-1)\frac{e^{-2x}}{2} + \int (2x+2)\frac{e^{-2x}}{2}\,dx = -\frac{(x^2+2x-1)e^{-2x}}{2} + \int (x+1)e^{-2x}\,dx.\]

A második integrál:

\[\int (x+1)e^{-2x}\,dx = -(x+1)\frac{e^{-2x}}{2} + \frac12\int e^{-2x}\,dx = -\frac{(x+1)e^{-2x}}{2} - \frac{e^{-2x}}{4} + c.\]

Visszaírva:

\[\int (x^2+2x-1)e^{-2x}\,dx = -\frac{e^{-2x}}{4}\Big(2(x^2+2x-1) + 2(x+1) + 1\Big) + c = -\frac{(2x^2 + 6x + 1)\,e^{-2x}}{4} + c.\]

Eredmény: \(-\dfrac{(2x^2+6x+1)\,e^{-2x}}{4} + c\quad (x, c \in \R)\)

Részletes magyarázat

Szereposztás: \(f = P\) (polinom), \(g' = e^{-2x}\). Minden parciális integrálás eggyel csökkenti a polinom fokát, így másodfokú polinomnál két lépés kell.

Előjel: az \(e^{-2x}\) primitív függvénye \(-\frac{e^{-2x}}{2}\), ezért a \(-\int f'g\) tag előjele pozitívra fordul.

Ellenőrzés: \(\Big(-\frac{(2x^2+6x+1)e^{-2x}}{4}\Big)' = -\frac{(4x+6)e^{-2x} - 2(2x^2+6x+1)e^{-2x}}{4} = \frac{(4x^2 + 8x - 4)e^{-2x}}{4} = (x^2+2x-1)e^{-2x}\). ✓

Gyorsabb út (határozatlan együtthatók): a primitív függvény \((Ax^2 + Bx + C)e^{-2x}\) alakú. Deriválva és összevetve: \(-2A = 1\), \(2A - 2B = 2\), \(B - 2C = -1\), azaz \(A = -\frac12\), \(B = -\frac32\), \(C = -\frac14\).

A másik két változat eredménye:

  • \(e^{2x}\)-szel (a gyakorlati anyag megoldása): \(\displaystyle\int (x^2+2x-1)e^{2x}\,dx = \frac{(2x^2 + 2x - 3)\,e^{2x}}{4} + c\).
  • \(e^{-3x}\)-szel (összevont anyag): \(\displaystyle\int (x^2+2x-1)e^{-3x}\,dx = -\frac{(9x^2 + 24x - 1)\,e^{-3x}}{27} + c\).
3. (b)7. gyakorlat · óraiparciális integrálás · egyenlet
\[\int e^{2x}\sin x\,dx \quad (x \in \R)\]
Megoldás

Legyen \(I := \int e^{2x}\sin x\,dx\). A trigonometrikus rész a \(g'\):

\[I = \int e^{2x}(-\cos x)'\,dx = -e^{2x}\cos x + 2\int e^{2x}\cos x\,dx,\] \[\int e^{2x}\cos x\,dx = \int e^{2x}(\sin x)'\,dx = e^{2x}\sin x - 2\int e^{2x}\sin x\,dx = e^{2x}\sin x - 2I.\]

Visszaírva:

\[I = -e^{2x}\cos x + 2e^{2x}\sin x - 4I \quad\Longrightarrow\quad 5I = e^{2x}(2\sin x - \cos x).\]

Eredmény: \(\dfrac{e^{2x}(2\sin x - \cos x)}{5} + c\quad (x, c \in \R)\)

Részletes magyarázat

Miért egyenlet? Két parciális integrálás után visszakapjuk a kiinduló integrált (\(-4\)-szeres szorzóval). Ezt átvisszük a bal oldalra, és kifejezzük \(I\)-t. A konstanst a végén írjuk hozzá.

Fontos: a második lépésben is ugyanazt a szerepet kell adni a trigonometrikus résznek (\(g'\)). Ha ott megcserélnéd, egyszerűen visszakapnád az \(I = I\) azonosságot.

Ellenőrzés: \(\Big(\frac{e^{2x}(2\sin x - \cos x)}{5}\Big)' = \frac{e^{2x}\big(2(2\sin x - \cos x) + 2\cos x + \sin x\big)}{5} = \frac{5e^{2x}\sin x}{5} = e^{2x}\sin x\). ✓

Általános képlet: \(\int e^{\alpha x}\sin(ax)\,dx = \frac{e^{\alpha x}(\alpha\sin ax - a\cos ax)}{\alpha^2 + a^2} + c\). Itt \(\alpha = 2\), \(a = 1\).

3. (c)7. gyakorlat · óraiparciális integrálás · ln
\[\int x^2\ln x\,dx \quad (x \gt 0)\]
Megoldás

Most a polinom a \(g'\): \(x^2 = \big(\frac{x^3}{3}\big)'\).

\[\int x^2\ln x\,dx = \frac{x^3}{3}\ln x - \int \frac{x^3}{3}\cdot\frac1x\,dx = \frac{x^3}{3}\ln x - \frac13\int x^2\,dx = \frac{x^3}{3}\ln x - \frac{x^3}{9} + c.\]

Eredmény: \(\frac{x^3}{3}\ln x - \frac{x^3}{9} + c\quad (x \gt 0,\ c \in \R)\)

Részletes magyarázat

Miért fordított a szereposztás? A \(\ln x\)-nek nem ismerjük „kényelmesen” a primitív függvényét, de a deriváltja \(\frac1x\), ami a polinommal összeszorozva egyszerűsödik. Ezért \(f = \ln x\) (deriváljuk), \(g' = x^2\) (integráljuk).

Ellenőrzés: \(\big(\frac{x^3}{3}\ln x - \frac{x^3}{9}\big)' = x^2\ln x + \frac{x^2}{3} - \frac{x^2}{3} = x^2\ln x\). ✓

3. (d)7. gyakorlat · órai\(1\cdot G\) trükk
\[\int \arctg(3x)\,dx \quad (x \in \R)\]
Megoldás
\[\int 1\cdot\arctg(3x)\,dx = x\arctg(3x) - \int x\cdot\frac{3}{1 + 9x^2}\,dx = x\arctg(3x) - \frac16\int\frac{18x}{1 + 9x^2}\,dx\] \[= x\arctg(3x) - \frac16\ln(1 + 9x^2) + c.\]

Eredmény: \(x\arctg(3x) - \frac16\ln(1+9x^2) + c\quad (x, c \in \R)\)

Részletes magyarázat

A trükk: \(\arctg(3x) = (x)'\cdot\arctg(3x)\), azaz \(g' = 1\), \(f = \arctg(3x)\). Így az \(\arctg\) helyett annak (racionális) deriváltja jelenik meg.

Láncszabály: \(\big(\arctg(3x)\big)' = \frac{1}{1 + (3x)^2}\cdot 3\).

A maradék integrál \(\frac{f'}{f}\) típusú: \((1 + 9x^2)' = 18x\), ezért \(\frac{3x}{1+9x^2} = \frac16\cdot\frac{18x}{1+9x^2}\).

Ellenőrzés: \(\big(x\arctg 3x - \frac16\ln(1+9x^2)\big)' = \arctg 3x + \frac{3x}{1+9x^2} - \frac{3x}{1+9x^2} = \arctg 3x\). ✓

4.7. gyakorlat · óraiparciális integrálás · egyenlet

Parciális integrálással számítsuk ki a következő határozatlan integrált:

\[\int \sqrt{1 - x^2}\,dx \quad \big(x \in (-1, 1)\big)\]
Megoldás

Legyen \(I := \int\sqrt{1-x^2}\,dx\), és írjuk \(1\cdot\sqrt{1-x^2}\) alakba:

\[I = x\sqrt{1-x^2} - \int x\cdot\frac{-x}{\sqrt{1-x^2}}\,dx = x\sqrt{1-x^2} - \int\frac{(1 - x^2) - 1}{\sqrt{1-x^2}}\,dx\] \[= x\sqrt{1-x^2} - \int\sqrt{1-x^2}\,dx + \int\frac{dx}{\sqrt{1-x^2}} = x\sqrt{1-x^2} - I + \arcsin x.\]

Tehát \(2I = x\sqrt{1-x^2} + \arcsin x\).

Eredmény: \(\dfrac{x\sqrt{1-x^2} + \arcsin x}{2} + c\quad \big(x \in (-1,1),\ c \in \R\big)\)

Részletes magyarázat

Kulcslépés: az \(x^2 = -\big((1-x^2) - 1\big)\) átírás. Így a tört szétesik \(\sqrt{1-x^2}\)-re (ez maga \(I\)) és \(\frac{1}{\sqrt{1-x^2}}\)-re (alapintegrál: \(\arcsin\)).

Ellenőrzés: \(\Big(\frac{x\sqrt{1-x^2} + \arcsin x}{2}\Big)' = \frac12\Big(\sqrt{1-x^2} - \frac{x^2}{\sqrt{1-x^2}} + \frac{1}{\sqrt{1-x^2}}\Big) = \frac12\cdot\frac{2(1-x^2)}{\sqrt{1-x^2}} = \sqrt{1-x^2}\). ✓

Az előadáson ugyanezt az \(x = \sin t\) helyettesítéssel (második helyettesítési szabály) oldották meg: \(\int\cos^2 t\,dt = \frac t2 + \frac{\sin 2t}{4}\), és \(t = \arcsin x\), \(\frac{\sin 2t}{4} = \frac{\sin t\cos t}{2} = \frac{x\sqrt{1-x^2}}{2}\). Ugyanaz jön ki.

7. gyakorlat · Házi feladatok · saját megoldás

Házi feladatok

Az összevont gyakorlati anyag 7. gyakorlathoz tartozó házi feladatai. Ezekhez nincs hivatalos megoldás, ezek saját megoldások (deriválással ellenőrizve).

1. (a)7. gyakorlat · házi\(f^\alpha f'\) típus
\[\int \frac{1}{\cos^2 x}\cdot\frac{1}{\sqrt{1 + \tg x}}\,dx \quad \big(x \in (-\tfrac\pi2, \tfrac\pi2)\big)\]

Megjegyzés a forráshoz. A gyök alatt \(1 + \tg x \gt 0\) kell, azaz \(\tg x \gt -1\), ami a \((-\frac\pi2, \frac\pi2)\) intervallumon csak \(x \gt -\frac\pi4\) esetén teljesül. A feladat tehát valójában az \(x \in (-\frac\pi4, \frac\pi2)\) intervallumon értelmes.

Megoldás

Ha \(x \in (-\frac\pi4, \frac\pi2)\), akkor \(1 + \tg x \gt 0\), és \((1 + \tg x)' = \frac{1}{\cos^2 x}\), így

\[\int (1 + \tg x)^{-1/2}\cdot(1 + \tg x)'\,dx = \frac{(1 + \tg x)^{1/2}}{1/2} + c = 2\sqrt{1 + \tg x} + c.\]

Eredmény: \(2\sqrt{1 + \tg x} + c\quad \big(x \in (-\tfrac\pi4, \tfrac\pi2),\ c \in \R\big)\)

Részletes magyarázat

Felismerés: ugyanaz a minta, mint az órai 2(f)-ben: \(\frac{1}{\cos^2 x}\) a \(\tg x\) (és így az \(1 + \tg x\)) deriváltja. \(f = 1 + \tg x\), \(\alpha = -\frac12\).

Ellenőrzés: \(\big(2\sqrt{1+\tg x}\big)' = 2\cdot\frac{1}{2\sqrt{1+\tg x}}\cdot\frac{1}{\cos^2 x}\). ✓

1. (b)7. gyakorlat · házielső helyettesítés · arctg
\[\int \frac{1}{x(1 + \ln^2 x)}\,dx \quad \big(x \in (0, +\infty)\big)\]
Megoldás

Az első helyettesítési szabály \(f(u) = \frac{1}{1+u^2}\), \(F = \arctg\) és \(g(x) = \ln x\), \(g'(x) = \frac1x\) választással:

\[\int \frac{1}{1 + (\ln x)^2}\cdot(\ln x)'\,dx = \arctg(\ln x) + c.\]

Eredmény: \(\arctg(\ln x) + c\quad (x \gt 0,\ c \in \R)\)

Részletes magyarázat

Felismerés: az \(\frac1x\) a \(\ln x\) deriváltja, a maradék pedig \(\frac{1}{1+u^2}\) alakú, ahol \(u = \ln x\). Ez nem a három speciális eset egyike, hanem az általános \(\int f(g(x))g'(x)\,dx = F(g(x)) + c\) szabály.

Ellenőrzés: \(\big(\arctg(\ln x)\big)' = \frac{1}{1 + \ln^2 x}\cdot\frac1x\). ✓

1. (c)7. gyakorlat · háziparciális integrálás · egyenlet
\[\int \cos(2x + 1)\cdot e^{3x+2}\,dx \quad (x \in \R)\]
Megoldás

Legyen \(I := \int e^{3x+2}\cos(2x+1)\,dx\). Kétszer integrálunk parciálisan, mindkétszer az exponenciális rész a \(g'\): \(e^{3x+2} = \big(\frac{e^{3x+2}}{3}\big)'\).

\[I = \frac{e^{3x+2}}{3}\cos(2x+1) + \frac23\int e^{3x+2}\sin(2x+1)\,dx,\] \[\int e^{3x+2}\sin(2x+1)\,dx = \frac{e^{3x+2}}{3}\sin(2x+1) - \frac23\,I.\]

Visszaírva:

\[I = \frac{e^{3x+2}}{3}\cos(2x+1) + \frac{2e^{3x+2}}{9}\sin(2x+1) - \frac49\,I \;\Longrightarrow\; \frac{13}{9}I = \frac{e^{3x+2}}{9}\big(3\cos(2x+1) + 2\sin(2x+1)\big).\]

Eredmény: \(\dfrac{e^{3x+2}\big(3\cos(2x+1) + 2\sin(2x+1)\big)}{13} + c\quad (x, c \in \R)\)

Részletes magyarázat

Minta: ugyanaz, mint az órai 3(b): \(e^{\alpha x + \beta}\cdot G(ax+b)\) alak, két parciális integrálás után visszakapjuk \(I\)-t. Itt az exponenciálist választottuk \(g'\)-nek; ez is jó, csak mindkét lépésben ugyanígy kell.

Előjelek: \(\big(\cos(2x+1)\big)' = -2\sin(2x+1)\), ezért az első lépésben \(-\int f'g = +\frac23\int e^{3x+2}\sin(2x+1)\,dx\). A második lépésben \(\big(\sin(2x+1)\big)' = 2\cos(2x+1)\), így ott \(-\frac23 I\) jön.

Ellenőrzés: legyen \(u = 2x+1\). \(\Big(e^{3x+2}(3\cos u + 2\sin u)\Big)' = e^{3x+2}\big(9\cos u + 6\sin u - 6\sin u + 4\cos u\big) = 13\,e^{3x+2}\cos u\). Osztva 13-mal ✓.

1. (d)7. gyakorlat · házi\(1\cdot G\) trükk
\[\int \arcsin(3x)\,dx \quad (x \in \R)\]

Megjegyzés a forráshoz. Az \(\arcsin(3x)\) csak \(|3x| \le 1\) esetén értelmes, és a primitív függvény a nyílt \(x \in (-\frac13, \frac13)\) intervallumon kereshető. Az „\(x \in \R\)” elírás.

Megoldás

Ha \(x \in (-\frac13, \frac13)\), akkor

\[\int 1\cdot\arcsin(3x)\,dx = x\arcsin(3x) - \int\frac{3x}{\sqrt{1 - 9x^2}}\,dx.\]

A maradék \(f^\alpha f'\) típusú (\(f = 1 - 9x^2 \gt 0\), \(f' = -18x\), \(\alpha = -\frac12\)):

\[\int\frac{3x}{\sqrt{1-9x^2}}\,dx = -\frac16\int(1 - 9x^2)^{-1/2}(-18x)\,dx = -\frac16\cdot 2\sqrt{1 - 9x^2} = -\frac13\sqrt{1 - 9x^2}.\]

Eredmény: \(x\arcsin(3x) + \frac13\sqrt{1 - 9x^2} + c\quad \big(x \in (-\tfrac13, \tfrac13),\ c \in \R\big)\)

Részletes magyarázat

Minta: ugyanaz, mint az órai 3(d) (\(\arctg 3x\)): \(g' = 1\), \(f = \arcsin(3x)\), \(f' = \frac{3}{\sqrt{1 - 9x^2}}\).

Ellenőrzés: \(\big(x\arcsin 3x + \frac13\sqrt{1-9x^2}\big)' = \arcsin 3x + \frac{3x}{\sqrt{1-9x^2}} + \frac13\cdot\frac{-18x}{2\sqrt{1-9x^2}} = \arcsin 3x\). ✓

Mire figyelj

Gyakori hibák

✕

\(\int f g = \int f\cdot\int g\). Szorzatra nincs ilyen szabály. Szorzatnál az első helyettesítési szabály (ha az egyik tényező a másik belső függvényének deriváltja) vagy a parciális integrálás segít.

✕

Hiányzó \(\frac1a\) a lineáris helyettesítésnél. \(\int\cos 2x\,dx = \frac{\sin 2x}{2}\), nem \(\sin 2x\). Deriválással azonnal kiderül.

✕

\(\int\sin^2 x\,dx = \frac{\sin^3 x}{3}\). Az \(f^\alpha f'\) típushoz kell az \(f'\) szorzó is. Páros kitevőjű \(\sin\), \(\cos\) esetén linearizálunk (órai 2(e)).

✕

Elfelejtett intervallum vagy előjel a logaritmusban. \(\int\frac{f'}{f} = \ln f\) csak \(f \gt 0\)-n; ha \(f \lt 0\), akkor \(\ln(-f)\) (órai 2(c) megjegyzése). Mindig nézd meg, hol dolgozol.

✕

Rossz szereposztás a parciális integrálásnál. \(\int x^2\ln x\)-nél ha \(g' = \ln x\) lenne, egyre bonyolultabb integrált kapnál. Az a jó szereposztás, ahol \(\int f'g\) egyszerűbb, mint az eredeti.

✕

Szerepcsere a „visszatérő” integráloknál. Az \(\int e^{\alpha x}\sin x\) típusnál a második parciális integrálásban is ugyanazt a tényezőt kell \(g'\)-nek venni, különben \(I = I\) jön ki (órai 3(b)).
