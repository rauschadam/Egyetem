Alapintegrálok

Hatványfüggvények

Az \(x^\alpha\) típusú függvények. A \(-1\) kitevő kivétel: ott logaritmus jön ki.

1.mindkét táblázathatvány
\[\int x^n\,dx \quad (x \in \R,\ n \in \mathbb N) = \;?\]
Megoldás

\(\dfrac{x^{n+1}}{n+1} + c\)

Részletes magyarázat

Ellenőrzés: \(\Big(\frac{x^{n+1}}{n+1}\Big)' = \frac{(n+1)x^n}{n+1} = x^n\). ✓

Miért \(\R\)? Nemnegatív egész kitevőnél \(x^n\) és \(x^{n+1}\) minden valós számra értelmes és deriválható. Az \(n = 0\) eset: \(\int 1\,dx = x + c\).

2.mindkét táblázatlogaritmus
\[\int \frac1x\,dx \quad \big(x \in (0,+\infty), \text{ ill. } x \in (-\infty, 0)\big) = \;?\]
Megoldás

\((0,+\infty)\text{-en } \ln x + c, \qquad (-\infty,0)\text{-n } \ln(-x) + c\)

Részletes magyarázat

Ellenőrzés: \((\ln x)' = \frac1x\), és a láncszabállyal \(\big(\ln(-x)\big)' = \frac{1}{-x}\cdot(-1) = \frac1x\). ✓

Két intervallum, két képlet: a primitív függvényt mindig intervallumon keressük, és \(\frac1x\) értelmezési tartománya két intervallumból áll. Röviden: \(\ln|x| + c\), de a 0 két oldalán a konstans különbözhet.

Miért nem \(\frac{x^0}{0}\)? Az \(\frac{x^{\alpha+1}}{\alpha+1}\) képlet \(\alpha = -1\)-re nullával osztana. Ezt a „lyukat” tölti ki a logaritmus.

3.mindkét táblázathatvány · negatív egész
\[\int \frac{1}{x^n}\,dx \quad \big(x \in (-\infty,0) \text{ vagy } (0,+\infty),\ n = 2, 3, 4, \dots\big) = \;?\]
Megoldás

\(\dfrac{1}{(1-n)\,x^{n-1}} + c\)

Részletes magyarázat

Levezetés: \(\frac{1}{x^n} = x^{-n}\), és \(\int x^{-n}\,dx = \frac{x^{-n+1}}{-n+1} = \frac{1}{(1-n)x^{n-1}}\).

Ellenőrzés: \(\big((1-n)^{-1}x^{1-n}\big)' = (1-n)^{-1}(1-n)x^{-n} = \frac{1}{x^n}\). ✓

Példa: \(\int\frac{dx}{x^2} = -\frac1x + c\). Egész kitevő miatt negatív \(x\)-re is jó, tehát a 0 mindkét oldalán ugyanaz a képlet.

4.mindkét táblázathatvány · valós kitevő
\[\int x^\alpha\,dx \quad \big(x \in (0,+\infty),\ \alpha \in \R \setminus \{-1\}\big) = \;?\]
Megoldás

\(\dfrac{x^{\alpha+1}}{\alpha+1} + c\)

Részletes magyarázat

Ellenőrzés: \(\Big(\frac{x^{\alpha+1}}{\alpha+1}\Big)' = x^\alpha\). ✓

Miért csak \((0,+\infty)\)? Valós (pl. \(\frac12\), \(\sqrt2\)) kitevőre \(x^\alpha := e^{\alpha\ln x}\), ez csak \(x \gt 0\)-ra értelmes.

Gyakori alakok: \(\int\sqrt x\,dx = \frac23 x^{3/2}\), \(\int\frac{dx}{\sqrt x} = 2\sqrt x\), \(\int\sqrt[3]{x^2}\,dx = \frac35 x^{5/3}\).

Exponenciális függvények

Az \(e^x\) a deriválás „fixpontja”, \(a^x\)-nél egy \(\ln a\) szorzó jelenik meg.

5.mindkét táblázatexponenciális
\[\int e^x\,dx \quad (x \in \R) = \;?\]
Megoldás

\(e^x + c\)

Részletes magyarázat

Ellenőrzés: \((e^x)' = e^x\). ✓

Lineáris helyettesítéssel: \(\int e^{ax+b}\,dx = \frac{e^{ax+b}}{a} + c\) \((a \ne 0)\), pl. \(\int e^{-2x}\,dx = -\frac{e^{-2x}}{2} + c\).

6.mindkét táblázatexponenciális
\[\int a^x\,dx \quad \big(x \in \R,\ a \in (0,1) \cup (1,+\infty)\big) = \;?\]

Megjegyzés a forráshoz. Az int-tabl.pdf-ben itt \(I = (0,+\infty)\) szerepel, de a képlet az egész \(\R\)-en igaz (az Alapintegralok.pdf is \(\R\)-et ír).

Megoldás

\(\dfrac{a^x}{\ln a} + c\)

Részletes magyarázat

Ellenőrzés: \(a^x = e^{x\ln a}\), így \((a^x)' = a^x\ln a\), tehát \(\big(\frac{a^x}{\ln a}\big)' = a^x\). ✓

Miért \(a \ne 1\)? \(a = 1\)-re \(\ln a = 0\), és amúgy is \(1^x = 1\), aminek primitív függvénye \(x\).

Példa: \(\int 2^x\,dx = \frac{2^x}{\ln 2} + c\).

Trigonometrikus függvények

A \(\tg\) és a \(\ctg\) primitív függvénye csak az int-tabl.pdf-ben szerepel; mindkettő \(\frac{f'}{f}\) típusú.

7.mindkét táblázattrigonometrikus
\[\int \sin x\,dx \quad (x \in \R) = \;?\]
Megoldás

\(-\cos x + c\)

Részletes magyarázat

Ellenőrzés: \((-\cos x)' = \sin x\). ✓

Előjel-emlékeztető: deriválva \(\sin \to \cos \to -\sin \to -\cos \to \sin\). Integrálni ezen a körön visszafelé kell lépni, ezért \(\int\sin = -\cos\).

8.mindkét táblázattrigonometrikus
\[\int \cos x\,dx \quad (x \in \R) = \;?\]
Megoldás

\(\sin x + c\)

Részletes magyarázat

Ellenőrzés: \((\sin x)' = \cos x\). ✓

Lineáris helyettesítéssel: \(\int\cos(2x+1)\,dx = \frac{\sin(2x+1)}{2} + c\).

9.int-tabl.pdf\(\frac{f'}{f}\) típus
\[\int \tg x\,dx \quad \big(x \in (-\tfrac\pi2, \tfrac\pi2)\big) = \;?\]
Megoldás

\(-\ln\cos x + c\)

Részletes magyarázat

Levezetés: \(\tg x = \frac{\sin x}{\cos x} = -\frac{(\cos x)'}{\cos x}\), és a \((-\frac\pi2,\frac\pi2)\) intervallumon \(\cos x \gt 0\), így \(\int\tg x\,dx = -\ln\cos x + c\).

Ellenőrzés: \((-\ln\cos x)' = -\frac{-\sin x}{\cos x} = \tg x\). ✓

Miért ez az intervallum? A \(\tg\) a \(\frac\pi2 + k\pi\) pontokban nincs értelmezve; a táblázat a 0-t tartalmazó intervallumot adja meg.

10.int-tabl.pdf\(\frac{f'}{f}\) típus
\[\int \ctg x\,dx \quad \big(x \in (0, \pi)\big) = \;?\]
Megoldás

\(\ln\sin x + c\)

Részletes magyarázat

Levezetés: \(\ctg x = \frac{\cos x}{\sin x} = \frac{(\sin x)'}{\sin x}\), és \((0,\pi)\)-n \(\sin x \gt 0\).

Ellenőrzés: \((\ln\sin x)' = \frac{\cos x}{\sin x} = \ctg x\). ✓

11.mindkét táblázattrigonometrikus
\[\int \frac{1}{\cos^2 x}\,dx \quad \big(x \in (-\tfrac\pi2, \tfrac\pi2)\big) = \;?\]
Megoldás

\(\tg x + c\)

Részletes magyarázat

Ellenőrzés: \((\tg x)' = \frac{\cos x\cos x - \sin x(-\sin x)}{\cos^2 x} = \frac{1}{\cos^2 x}\). ✓

Ahol előkerül: az \(f^\alpha f'\) típusban \(f = \tg x\) mellett (7. gyakorlat, órai 2(f) és házi 1(a)).

12.mindkét táblázattrigonometrikus
\[\int \frac{1}{\sin^2 x}\,dx \quad \big(x \in (0, \pi)\big) = \;?\]
Megoldás

\(-\ctg x + c\)

Részletes magyarázat

Ellenőrzés: \((\ctg x)' = \frac{-\sin^2 x - \cos^2 x}{\sin^2 x} = -\frac{1}{\sin^2 x}\), tehát \((-\ctg x)' = \frac{1}{\sin^2 x}\). ✓

Miért \((0,\pi)\)? A \(\ctg\) a \(k\pi\) pontokban nincs értelmezve; \((0,\pi)\) az egyik maximális intervallum.

Alapintegrálok

Hiperbolikus függvények

Definíciók: \(\operatorname{sh} x = \frac{e^x - e^{-x}}{2}\), \(\operatorname{ch} x = \frac{e^x + e^{-x}}{2}\), \(\operatorname{th} x = \frac{\operatorname{sh} x}{\operatorname{ch} x}\), \(\operatorname{cth} x = \frac{\operatorname{ch} x}{\operatorname{sh} x}\). Deriváltak: \(\operatorname{sh}' = \operatorname{ch}\), \(\operatorname{ch}' = \operatorname{sh}\) (előjelváltás nincs!), és \(\operatorname{ch}^2 x - \operatorname{sh}^2 x = 1\).

13.mindkét táblázathiperbolikus
\[\int \operatorname{sh} x\,dx \quad (x \in \R) = \;?\]
Megoldás

\(\operatorname{ch} x + c\)

Részletes magyarázat

Ellenőrzés: \(\Big(\frac{e^x + e^{-x}}{2}\Big)' = \frac{e^x - e^{-x}}{2} = \operatorname{sh} x\). ✓

Különbség a \(\sin\)-hoz képest: itt nincs mínusz előjel: \(\int\sin = -\cos\), de \(\int\operatorname{sh} = +\operatorname{ch}\).

14.mindkét táblázathiperbolikus
\[\int \operatorname{ch} x\,dx \quad (x \in \R) = \;?\]
Megoldás

\(\operatorname{sh} x + c\)

Részletes magyarázat

Ellenőrzés: \(\Big(\frac{e^x - e^{-x}}{2}\Big)' = \frac{e^x + e^{-x}}{2} = \operatorname{ch} x\). ✓

15.int-tabl.pdf\(\frac{f'}{f}\) típus
\[\int \operatorname{th} x\,dx \quad (x \in \R) = \;?\]
Megoldás

\(\ln\operatorname{ch} x + c\)

Részletes magyarázat

Levezetés: \(\operatorname{th} x = \frac{\operatorname{sh} x}{\operatorname{ch} x} = \frac{(\operatorname{ch} x)'}{\operatorname{ch} x}\), és \(\operatorname{ch} x \ge 1 \gt 0\) minden \(x\)-re.

Ellenőrzés: \((\ln\operatorname{ch} x)' = \frac{\operatorname{sh} x}{\operatorname{ch} x}\). ✓ Ez a \(\int\tg x = -\ln\cos x\) párja, de előjel nélkül.

16.int-tabl.pdf\(\frac{f'}{f}\) típus
\[\int \operatorname{cth} x\,dx \quad \big(x \in (0,+\infty), \text{ ill. } x \in (-\infty, 0)\big) = \;?\]
Megoldás

\((0,+\infty)\text{-en } \ln\operatorname{sh} x + c, \qquad (-\infty,0)\text{-n } \ln\operatorname{sh}(-x) + c\)

Részletes magyarázat

Levezetés: \(\operatorname{cth} x = \frac{(\operatorname{sh} x)'}{\operatorname{sh} x}\). Ha \(x \gt 0\), akkor \(\operatorname{sh} x \gt 0\) és \(\ln\operatorname{sh} x\) a primitív függvény. Ha \(x \lt 0\), akkor \(\operatorname{sh} x \lt 0\), és \(\ln(-\operatorname{sh} x) = \ln\operatorname{sh}(-x)\), mert \(\operatorname{sh}\) páratlan.

Ellenőrzés \(x \lt 0\)-ra: \(\big(\ln\operatorname{sh}(-x)\big)' = \frac{\operatorname{ch}(-x)\cdot(-1)}{\operatorname{sh}(-x)} = \frac{-\operatorname{ch} x}{-\operatorname{sh} x} = \operatorname{cth} x\). ✓

Tömören: \(\ln|\operatorname{sh} x| + c\), ugyanúgy, mint \(\int\frac1x = \ln|x|\).

17.mindkét táblázathiperbolikus
\[\int \frac{1}{\operatorname{ch}^2 x}\,dx \quad (x \in \R) = \;?\]
Megoldás

\(\operatorname{th} x + c\)

Részletes magyarázat

Ellenőrzés: \((\operatorname{th} x)' = \frac{\operatorname{ch}^2 x - \operatorname{sh}^2 x}{\operatorname{ch}^2 x} = \frac{1}{\operatorname{ch}^2 x}\). ✓ (A \(\operatorname{ch}^2 - \operatorname{sh}^2 = 1\) azonosság kell.)

18.mindkét táblázathiperbolikus
\[\int \frac{1}{\operatorname{sh}^2 x}\,dx \quad \big(x \in (-\infty,0) \text{ vagy } (0,+\infty)\big) = \;?\]
Megoldás

\(-\operatorname{cth} x + c\)

Részletes magyarázat

Ellenőrzés: \((\operatorname{cth} x)' = \frac{\operatorname{sh}^2 x - \operatorname{ch}^2 x}{\operatorname{sh}^2 x} = -\frac{1}{\operatorname{sh}^2 x}\), tehát \((-\operatorname{cth} x)' = \frac{1}{\operatorname{sh}^2 x}\). ✓

Miért nem \(\R\)? \(\operatorname{sh} 0 = 0\), a 0-ban az integrandus nincs értelmezve.

Alapintegrálok

Racionális és gyökös integrandusok (arc, ar függvények)

Ezek primitív függvényei az inverz trigonometrikus (arc) és az area (ar) függvények. Az ar függvények logaritmusos alakja csak az int-tabl.pdf-ben szerepel.

19.mindkét táblázatarctg
\[\int \frac{1}{1 + x^2}\,dx \quad (x \in \R) = \;?\]
Megoldás

\(\arctg x + c \;\Big(= \tfrac\pi2 - \operatorname{arc\,ctg} x + c\Big)\)

Részletes magyarázat

Ellenőrzés: \((\arctg x)' = \frac{1}{1 + \tg^2(\arctg x)} = \frac{1}{1+x^2}\). ✓

Miért ugyanaz a két alak? \(\arctg x + \operatorname{arc\,ctg} x = \frac\pi2\), így a kettő csak konstansban különbözik.

Gyakori változat: \(\int\frac{dx}{x^2 + k^2} = \frac1k\arctg\frac xk + c\) (8. gyakorlat, 3. alaptípus).

20.int-tabl.pdfarth · arcth
\[\int \frac{1}{1 - x^2}\,dx \quad \big(x \in (-1, 1), \text{ ill. } x \in (-\infty,-1) \text{ vagy } (1,+\infty)\big) = \;?\]
Megoldás

\((-1,1)\text{-en } \operatorname{arth} x = \tfrac12\ln\tfrac{1+x}{1-x} + c, \qquad |x| \gt 1\text{-re } \operatorname{arcth} x = \tfrac12\ln\tfrac{x+1}{x-1} + c\)

Részletes magyarázat

Levezetés parciális törtekkel: \(\frac{1}{1-x^2} = \frac12\Big(\frac{1}{1+x} + \frac{1}{1-x}\Big)\), így \(\int\frac{dx}{1-x^2} = \frac12\big(\ln|1+x| - \ln|1-x|\big) = \frac12\ln\Big|\frac{1+x}{1-x}\Big| + c\).

A két eset: \((-1,1)\)-en \(\frac{1+x}{1-x} \gt 0\), ez az \(\operatorname{arth} x\). Ha \(|x| \gt 1\), akkor \(\big|\frac{1+x}{1-x}\big| = \frac{x+1}{x-1}\), ez az \(\operatorname{arcth} x\).

Ellenőrzés: \(\big(\tfrac12\ln\frac{x+1}{x-1}\big)' = \frac12\Big(\frac{1}{x+1} - \frac{1}{x-1}\Big) = \frac{1}{1-x^2}\). ✓

21.mindkét táblázatarcsin
\[\int \frac{1}{\sqrt{1 - x^2}}\,dx \quad \big(x \in (-1, 1)\big) = \;?\]
Megoldás

\(\arcsin x + c \;\Big(= \tfrac\pi2 - \arccos x + c\Big)\)

Részletes magyarázat

Ellenőrzés: \((\arcsin x)' = \frac{1}{\cos(\arcsin x)} = \frac{1}{\sqrt{1 - x^2}}\). ✓

Miért nyílt intervallum? A \(\pm1\)-ben a nevező 0, ott az \(\arcsin\) sem deriválható.

Gyakori változat: \(\int\frac{dx}{\sqrt{k^2 - x^2}} = \arcsin\frac xk + c\) \((|x| \lt k)\).

22.mindkét táblázatarsh
\[\int \frac{1}{\sqrt{x^2 + 1}}\,dx \quad (x \in \R) = \;?\]
Megoldás

\(\operatorname{arsh} x + c = \ln\big(x + \sqrt{x^2 + 1}\big) + c\)

Részletes magyarázat

Ellenőrzés a logaritmusos alakkal: \(\big(\ln(x + \sqrt{x^2+1})\big)' = \frac{1 + \frac{x}{\sqrt{x^2+1}}}{x + \sqrt{x^2+1}} = \frac{\frac{\sqrt{x^2+1} + x}{\sqrt{x^2+1}}}{x + \sqrt{x^2+1}} = \frac{1}{\sqrt{x^2+1}}\). ✓

Honnan a logaritmus? Az \(y = \operatorname{sh} t = \frac{e^t - e^{-t}}{2}\) egyenletet \(e^t\)-re (másodfokú egyenletként) megoldva \(e^t = y + \sqrt{y^2+1}\).

23.mindkét táblázatarch
\[\int \frac{1}{\sqrt{x^2 - 1}}\,dx \quad \big(x \in (1,+\infty), \text{ ill. } x \in (-\infty,-1)\big) = \;?\]

Megjegyzés a forráshoz. Az Alapintegralok.pdf utolsó sorában az intervallum \((-\infty, 1)\), ez elírás: \(\sqrt{x^2-1}\) csak \(|x| \ge 1\)-re értelmes, a helyes intervallum \((-\infty,-1)\) (az int-tabl.pdf is így írja).

Megoldás

\((1,+\infty)\text{-en } \operatorname{arch} x = \ln\big(x + \sqrt{x^2-1}\big) + c, \qquad (-\infty,-1)\text{-en } -\operatorname{arch}(-x) + c\)

Részletes magyarázat

Ellenőrzés \(x \gt 1\)-re: \(\big(\ln(x + \sqrt{x^2-1})\big)' = \frac{1 + \frac{x}{\sqrt{x^2-1}}}{x + \sqrt{x^2-1}} = \frac{1}{\sqrt{x^2-1}}\). ✓

A negatív oldal: \(\big(\operatorname{arch}(-x)\big)' = \frac{1}{\sqrt{x^2-1}}\cdot(-1)\), ezért \(\int\frac{dx}{\sqrt{x^2-1}} = -\operatorname{arch}(-x) + c\). Az int-tabl.pdf ugyanezt fordítva írja: \(\int -\frac{1}{\sqrt{x^2-1}}\,dx = \operatorname{arch}(-x) = \ln\big(-x + \sqrt{x^2-1}\big)\).

Tömören: mindkét oldalon \(\ln\big|x + \sqrt{x^2-1}\big| + c\), mert \(-\ln(-x + \sqrt{x^2-1}) = \ln\frac{1}{-x+\sqrt{x^2-1}} = \ln\big(-x - \sqrt{x^2-1}\big)\).

Mire figyelj

Gyakori hibák

✕

Előjelhiba a trigonometrikus függvényeknél. \(\int\sin x\,dx = -\cos x\), de \(\int\operatorname{sh} x\,dx = +\operatorname{ch} x\). Ha bizonytalan vagy, deriválj vissza.

✕

\(\int\frac1x = \frac{x^0}{0}\). A hatványképlet \(\alpha = -1\)-re nem működik, ott \(\ln x\) (ill. \(\ln(-x)\)) a válasz.

✕

\(\int a^x = \frac{a^{x+1}}{x+1}\). Ez a hatványfüggvény képlete. Az exponenciálisnál a kitevőben van a változó: \(\frac{a^x}{\ln a}\).

✕

Elfelejtett intervallum. Minden alapintegrál csak a megadott intervallumon érvényes. \(\frac1x\), \(\operatorname{cth}\), \(\frac{1}{1-x^2}\), \(\frac{1}{\sqrt{x^2-1}}\) esetén a két oldalon más a képlet.

✕

\(\frac{1}{1+x^2}\) és \(\frac{1}{1-x^2}\) összekeverése. Az első \(\arctg\), a második \(\operatorname{arth}\) (logaritmus). A gyökös párjaik: \(\frac{1}{\sqrt{1-x^2}} \to \arcsin\), \(\frac{1}{\sqrt{1+x^2}} \to \operatorname{arsh}\).
