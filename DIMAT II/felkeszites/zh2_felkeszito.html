Képletlap

Amit fejből kell tudni. Az előadásjegyzet (Mérai) még nem tartalmazza a polinomokat, ezért itt a szokásos definíciók szerepelnek.

5/1

ℤp és az inverz

ℤm = {0, 1, …, m − 1}, a műveletek eredményét mod m vesszük.

a-nak akkor van inverze mod m, ha (a, m) = 1. Ha p prím, minden a ≠ 0 invertálható, vagyis ℤp test.

Keresés: kis p-nél próbálgatás (a · b ≡ 1), nagynál bővített euklideszi algoritmus, vagy Fermat: a−1 ≡ ap−2.

5/2

Szorzat foka, együtthatói

Ha f = Σ ai xi, g = Σ bj xj, akkor fg-ben

ck = Σi+j=k aibj

Test felett (pl. ℚ, ℤp) deg(fg) = deg f + deg g, mert a főegyütthatók szorzata nem 0. ℤ4-ben ez nem igaz: (2x + 1)2 = 1.

5/3

Maradékos osztás

Test feletti f, g ≠ 0 polinomhoz egyértelműen létezik q, r, hogy

f = q·g + r,   r = 0 vagy deg r < deg g

Egy lépés: f főtagja osztva g főtagjával, ez a hányados következő tagja. Kivonjuk a tag g-szeresét, és addig folytatjuk, amíg a maradék foka ≥ deg g.

ℤp-ben az osztás a főegyüttható inverzével való szorzás.

5/4–5/6

Oszthatóság, gyökök

  • g | f ⇔ a maradék 0. Paraméteresen: a maradék minden együtthatója 0 (több egyenlet).
  • Gyorsabb: írd fel f-et (ismeretlen hányados) · g alakban, bontsd ki, és hasonlítsd össze az együtthatókat.
  • f maradéka x − c-vel f(c). Ha g gyökei különbözők, r(c) = f(c) minden g(c) = 0 gyökre.
6/1–6/3

Számolás mod m

f ≡ g mod m ⇔ m | f − g. Összeadás, szorzás, hatványozás után is megmarad, ezért előbb redukálj, utána számolj.

Redukció: m főtagját kifejezzük. Pl. m = x2 + 1: x2 ≡ −1; m = x3 + 1: x3 ≡ −1, x4 ≡ −x.

A végeredmény foka mindig < deg m.

6/4

Polinomok lnko-ja

Euklideszi algoritmus, mint egészeknél: f = q1 g + r1, g = q2 r1 + r2, … Az utolsó nem nulla maradék az lnko.

Menet közben bármelyik maradék szorozható nem nulla konstanssal, ez az lnko-t nem változtatja meg. A végén legyen a főegyüttható 1.

6/5

Nagy hatványok

Keress kis k-t, amire xk ≡ 1 (vagy konstans) mod m. Ekkor n = kq + s esetén xn ≡ xs. Ha xk ≡ −1, akkor x2k ≡ 1.

ℤp-ben (a + b)p = ap + bp. Pl. ℤ2-ben (x2 + x + 1)2 = x4 + x2 + 1.

Ha nincs szabályosság: ismételt négyzetre emelés (a kitevő kettes számrendszerben).

7/1–7/3

Bővített euklideszi algoritmus

Táblázat r | q | u | v oszlopokkal, minden sorban r = u f + v g. Kezdősorok: (f, 1, 0) és (g, 0, 1); új sor = kettővel feljebbi − q · előző.

u f + v g = h megoldható ⇔ (f, g) | h. Ekkor az u0 f + v0 g = (f, g) sort szorozd h/(f, g)-vel.

Ha (f, g) = 1: u + k g, v − k f is megoldás. Egyszerűsítés: u mod g.

7/4–7/5

Közös gyök

(f, g) = 1 ⇔ nincs közös gyök (ℂ-ben) ⇔ u f + v g = 1 megoldható

Paraméteresen: ha az egyik polinom gyökei kiszámolhatók, helyettesítsd be őket a másikba. Ez sokkal gyorsabb, mint az euklidesz paraméterrel.

8/1, 8/6–8/7

Többszörös gyök

c többszörös gyöke f-nek ⇔ f(c) = 0 és f'(c) = 0. A többszörös gyökök éppen (f, f') gyökei.

Derivált: (a xn)' = n a xn−1, ℤp-ben n a-t mod p véve: (xp)' = 0!

Multiplicitás: Horner-elrendezés, ismételt osztás (x − c)-vel. ℤp-ben ne (f, f') kitevőiből olvasd le.

Paraméteres: f' gyökei a jelöltek, ezeket írd be f-be.

8/2–8/3

Irreducibilitás

  • 2- és 3-adfokú: irreducibilis ⇔ nincs gyöke.
  • 4-edfokú: nincs gyöke és nem két irreducibilis másodfokú szorzata.
  • Irreducibilis normált másodfokúak: ℤ2: x2 + x + 1; ℤ3: x2 + 1, x2 + x + 2, x2 + 2x + 2.
8/4–8/5, 8/8

Véges test 𝔽pn

Ha f ∈ ℤp[x] irreducibilis és n-edfokú, a maradékok mod f (foka < n) testet alkotnak, pn elemmel.

Számolás: szorzás, majd redukció a főtag kifejezésével (pl. x2 ≡ −1).

Inverz: ismeretlen együtthatókkal (b−1 = cx + d) vagy bővített euklidesszel: u b + v f = 1 ⇒ b−1 = u.

Másodfokú egyenlet (p ≠ 2): megoldóképlet, 2−1-gyel és a diszkrimináns gyökével a testben.

1.= 8/1 c)7 pont

Keresse meg az x8 + x7 + x6 + x5 + 2x4 + 2x3 + x2 ∈ ℤ3[x] polinom többszörös gyökeit!

Megoldás

Derivált (az együtthatókat mod 3 vesszük): f' = 8x7 + 7x6 + 6x5 + 5x4 + 8x3 + 6x2 + 2x ≡ 2x7 + x6 + 2x4 + 2x3 + 2x.

Euklideszi algoritmus f-re és f'-re:

f = (2x + 1) · f' + (2x4 + x)

f' = (x3 + 2x2 + 2) · (2x4 + x) + 0

Normálva (2−1 = 2): (f, f') = 2(2x4 + x) = x4 + 2x = x(x3 + 2) = x(x3 − 1) = x(x − 1)3, mert ℤ3-ban (x − 1)3 = x3 − 1.

A többszörös gyökök éppen (f, f') gyökei: 0 és 1. A multiplicitás: f = x2 · (x6 + x5 + x4 + x3 + 2x2 + 2x + 1), a második tényező 0-ban 1, tehát a 0 kétszeres. Az 1-et Horner-elrendezéssel háromszor lehet leosztani, negyedszer nem (lásd 8/1 c)).

0 (kétszeres) és 1 (háromszoros)  Teljes felbontás: f = x2 (x − 1)3 (x3 + x2 + x + 2).

Részletes magyarázat

Két út van, a gyakorlaton mindkettő elhangzott. 1. út: megkeresed a gyököket (0, 1, 2 behelyettesítése), és Horner-elrendezéssel nézed meg, hányszor oszthatók le. 2. út: (f, f') kiszámítása euklideszi algoritmussal. Ennél a polinomnál a 2. út két osztás, az 1. út is gyors, mert x2 kiemelhető.

Csapda ℤp-ben. Test feletti, 0 karakterisztikájú esetben (ℚ, ℂ) egy k-szoros gyök (f, f')-ben (k − 1)-szeres. ℤ3-ban ez nem igaz: (x − 1)3 deriváltja 3(x − 1)2 = 0, ezért (f, f')-ben is a teljes (x − 1)3 benne van. A multiplicitást tehát ne (f, f') kitevőiből olvasd le, hanem Hornerrel számold ki.

Pontozásra tipp. A derivált helyes felírása, az lnko és a gyökök külön is érnek pontot. Ha az idő szorít, a gyökök és a multiplicitás Hornerrel önmagában is teljes megoldás.

2.= 5/57 pont

Határozza meg a, b ∈ ℤ5 értékét úgy, hogy x4 + 3x2 + ax + b osztható legyen x2 + 3ax + 2-vel ℤ5 felett!

MegjegyzésA mintán „7. feladatsor 5. feladat” áll, de ez szó szerint az 5. feladatsor 5. feladata (a 7/5 a közös gyökös feladat). Vagyis a Zh az 5–8. sor anyagát kéri.
Megoldás

A hányados másodfokú, főegyütthatója 1: (x2 + cx + d)(x2 + 3ax + 2) = x4 + (3a + c)x3 + (2 + 3ac + d)x2 + (2c + 3ad)x + 2d.

  • x3: 3a + c = 0 → c = 2a
  • x2: 2 + 3ac + d = 3 → d = 1 − 6a2 = 1 − a2
  • x: 2c + 3ad = a → 4a + 3a(1 − a2) = a → a(1 − 3a2) = 0
  • 1: b = 2d

a = 0 vagy a2 = 3−1 = 2. ℤ5-ben a négyzetek 0, 1, 4, a 2 nincs köztük, így a = 0, d = 1, b = 2.

a = 0, b = 2  Ellenőrzés: (x2 + 1)(x2 + 2) = x4 + 3x2 + 2 ✓

3.= 8/78 pont

Mely b ∈ ℤ5 értékekre van az x4 + bx3 + 1 polinomnak többszörös gyöke?

Megoldás

c többszörös gyök ⇔ f(c) = 0 és f'(c) = 0. Itt f' = 4x3 + 3bx2 = x2(4x + 3b).

  • f'(c) = 0, ha c = 0: de f(0) = 1 ≠ 0.
  • vagy 4c + 3b = 0 → c = −3b · 4−1 = −3b · 4 = −12b ≡ 3b.

Behelyettesítve: f(3b) = 81b4 + b · 27b3 + 1 = 108b4 + 1 ≡ 3b4 + 1. Ha b = 0, ez 1; ha b ≠ 0, akkor b4 = 1 (kis Fermat), és 3 + 1 = 4. Egyik sem 0.

Nincs ilyen b – egyik b ∈ ℤ5-re sincs többszörös gyök.

Részletes magyarázat

Miért elég a c = 3b jelöltet nézni? Egy többszörös gyöknek f'-nek is gyökének kell lennie. f' gyökei (0 és 3b) mind ℤ5-ben vannak, tehát a „bővebb testben” sem lehet más közös gyök. Vagyis (f, f') = 1 minden b-re, ezt programmal is ellenőriztem.

Ellenőrzés kipróbálással: 5 eset van, mindegyikre megnézhető. Pl. b = 1: f = x4 + x3 + 1, c = 3: 81 + 27 + 1 = 109 ≡ 4 ≠ 0.

A „nincs ilyen b” is teljes értékű válasz, ha meg van indokolva. Ha gyanús, próbáld ki mind az 5 értéket, ez ℤ5-ben belefér az időbe.
4.= 8/4 a, c, d8 pont

Legyen f = x2 + 1 ∈ ℤ3[x] irreducibilis polinom és legyen 𝔽9 = {g mod f : g ∈ ℤ3[x]}. Legyen a = x, b = x + 1. Számítsa ki a következő értékeket 𝔽9-ben: a) a2; b) (2a + b)3; c) a−1!

Megoldás

Mod f: x2 ≡ −1 = 2.

  • a) a2 = x2 ≡ 2
  • b) 2a + b = 2x + x + 1 = 3x + 1 = 1, így (2a + b)3 = 13 = 1
  • c) x · 2x = 2x2 ≡ 2 · 2 = 4 ≡ 1, tehát a−1 = 2x
Részletes magyarázat

c) általános módszerrel. Keressük a−1 = cx + d alakban: x(cx + d) = cx2 + dx ≡ 2c + dx. Ez akkor 1, ha d = 0 és 2c = 1, azaz c = 2. Bővített euklideszi algoritmussal: x2 + 1 = x · x + 1, így 1 = f − x · x, és mod f: x · (−x) ≡ 1, a−1 = −x = 2x.

b) csapda: ne bontsd ki a köbre emelést! Előbb egyszerűsíts: 3x = 0 ℤ3-ban.
