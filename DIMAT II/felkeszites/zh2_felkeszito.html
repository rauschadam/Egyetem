Képletlap

Amit fejből kell tudni. Az előadásjegyzet (Mérai) még nem tartalmazza a polinomokat, ezért itt a szokásos definíciók szerepelnek.

5/1

ℤp és az inverz

ℤm = {0, 1, …, m − 1}, a műveletek eredményét mod m vesszük.

a-nak akkor van inverze mod m, ha (a, m) = 1. Ha p prím, minden a ≠ 0 invertálható, vagyis ℤp test.

Keresés: kis p-nél próbálgatás (a · b ≡ 1), nagynál bővített euklideszi algoritmus, vagy Fermat: a−1 ≡ ap−2.

5/2

Szorzat foka, együtthatói

Ha f = Σ ai xi, g = Σ bj xj, akkor fg-ben

ck = Σi+j=k aibj

Test felett (pl. ℚ, ℤp) deg(fg) = deg f + deg g, mert a főegyütthatók szorzata nem 0. ℤ4-ben ez nem igaz: (2x + 1)2 = 1.

5/3

Maradékos osztás

Test feletti f, g ≠ 0 polinomhoz egyértelműen létezik q, r, hogy

f = q·g + r,   r = 0 vagy deg r < deg g

Egy lépés: f főtagja osztva g főtagjával, ez a hányados következő tagja. Kivonjuk a tag g-szeresét, és addig folytatjuk, amíg a maradék foka ≥ deg g.

ℤp-ben az osztás a főegyüttható inverzével való szorzás.

5/4–5/6

Oszthatóság, gyökök

  • g | f ⇔ a maradék 0. Paraméteresen: a maradék minden együtthatója 0 (több egyenlet).
  • Gyorsabb: írd fel f-et (ismeretlen hányados) · g alakban, bontsd ki, és hasonlítsd össze az együtthatókat.
  • f maradéka x − c-vel f(c). Ha g gyökei különbözők, r(c) = f(c) minden g(c) = 0 gyökre.
6/1–6/3

Számolás mod m

f ≡ g mod m ⇔ m | f − g. Összeadás, szorzás, hatványozás után is megmarad, ezért előbb redukálj, utána számolj.

Redukció: m főtagját kifejezzük. Pl. m = x2 + 1: x2 ≡ −1; m = x3 + 1: x3 ≡ −1, x4 ≡ −x.

A végeredmény foka mindig < deg m.

6/4

Polinomok lnko-ja

Euklideszi algoritmus, mint egészeknél: f = q1 g + r1, g = q2 r1 + r2, … Az utolsó nem nulla maradék az lnko.

Menet közben bármelyik maradék szorozható nem nulla konstanssal, ez az lnko-t nem változtatja meg. A végén legyen a főegyüttható 1.

6/5

Nagy hatványok

Keress kis k-t, amire xk ≡ 1 (vagy konstans) mod m. Ekkor n = kq + s esetén xn ≡ xs. Ha xk ≡ −1, akkor x2k ≡ 1.

ℤp-ben (a + b)p = ap + bp. Pl. ℤ2-ben (x2 + x + 1)2 = x4 + x2 + 1.

Ha nincs szabályosság: ismételt négyzetre emelés (a kitevő kettes számrendszerben).

5/4érdekes

Hogyan kell megválasztani az a, b, m értékeket, hogy az x3 + ax + b polinom ℂ felett osztható legyen az x2 + mx − 1 polinommal?

Megoldás

1. út: maradékos osztás paraméterrel. x3 / x2 = x: kivonjuk x(x2 + mx − 1) = x3 + mx2 − x-et, marad −mx2 + (a + 1)x + b. Következő tag −m: kivonjuk −m(x2 + mx − 1) = −mx2 − m2 x + m-et:

r = (a + 1 + m2) x + (b − m)

Oszthatóság ⇔ r = 0 ⇔ mindkét együttható 0: a = −m2 − 1 és b = m.

2. út: együttható-összehasonlítás. A hányados elsőfokú és főegyütthatója 1: x3 + ax + b = (x + c)(x2 + mx − 1) = x3 + (m + c)x2 + (cm − 1)x − c. Összevetve: m + c = 0, a = cm − 1, b = −c, ebből ugyanaz jön ki.

m ∈ ℂ tetszőleges, a = −(m2 + 1), b = m

Ellenőrzés m = 0-ra: x3 − x = x(x2 − 1) ✓. m = 2-re: x3 − 5x + 2 = (x − 2)(x2 + 2x − 1) ✓.

Részletes magyarázat

Három ismeretlen van, de az oszthatóság csak két feltételt ad (a maradék két együtthatóját). Ezért az egyik paraméter szabadon választható, a válasz egy paraméteres család. Ezt így kell leírni: „bármely m-re, a = …, b = …”.

Az együttható-összehasonlítás akkor gyorsabb, ha a hányados alakja rögtön látszik: a fok 3 − 2 = 1, a főegyüttható 1/1 = 1, tehát x + c. Paraméteres osztásnál könnyű elrontani az előjeleket, ezt a módszert érdemes ellenőrzésre használni.

5/5érdekes

Határozza meg a, b ∈ ℤ5 értékét úgy, hogy x4 + 3x2 + ax + b osztható legyen x2 + 3ax + 2-vel ℤ5 felett!

Megoldás

A hányados másodfokú és főegyütthatója 1: (x2 + cx + d)(x2 + 3ax + 2). Kibontva:

x4 + (3a + c)x3 + (2 + 3ac + d)x2 + (2c + 3ad)x + 2d

Együtthatók összevetése x4 + 0x3 + 3x2 + ax + b-vel (mod 5):

  • x3: 3a + c = 0 → c = −3a = 2a
  • x2: 2 + 3ac + d = 3 → d = 1 − 3a · 2a = 1 − 6a2 = 1 − a2
  • x1: 2c + 3ad = a → 4a + 3a(1 − a2) − a = 0 → 6a − 3a3 = a − 3a3 = a(1 − 3a2) = 0
  • x0: b = 2d

ℤ5 test, így a = 0 vagy 3a2 = 1, azaz a2 = 3−1 = 2. A négyzetek ℤ5-ben 0, 1, 4, 4, 1, a 2 nincs köztük, tehát csak a = 0 jó.

Ekkor c = 0, d = 1, b = 2. Ellenőrzés: (x2 + 1)(x2 + 2) = x4 + 3x2 + 2 ✓.

a = 0, b = 2

Részletes magyarázat: maradékos osztással

Jelölje c = 3a. Az osztás három lépése után a maradék:

r = (a + 2c − c(1 + c2)) x + (b − 2(1 + c2))

c = 3a beírásával az x együtthatója a + 6a − 3a − 27a3 = 4a − 27a3 ≡ 4a − 2a3 = 2a(2 − a2). Ez ugyanaz a feltétel: a = 0 vagy a2 = 2 (nincs). A konstans: b = 2(1 + 0) = 2.

Mivel ℤ5-nek csak 5 eleme van, végső ellenőrzésként az a mind az 5 értéke kipróbálható. Ezt programmal meg is tettem, és csak (a, b) = (0, 2) jó.

5/6érdekes

Mi a maradék, ha az x64 + x54 + x14 + 1 ∈ ℂ[x] polinomot maradékosan elosztjuk az x2 − 1 polinommal?

Megoldás

Redukcióval. x2 ≡ 1 mod (x2 − 1), így minden páros kitevőjű hatvány: x2k = (x2)k ≡ 1. Tehát x64 + x54 + x14 + 1 ≡ 1 + 1 + 1 + 1 = 4.

Gyökökkel. A maradék r = cx + d alakú (foka < 2). x2 − 1 gyökei ±1, és ezekben f és r megegyezik: f(1) = 4 = c + d, f(−1) = 4 = −c + d. Így c = 0, d = 4.

r = 4

6. feladatsor · 10.12–16.

Maradék modulo polinom, lnko

Az „f mod m” azt a maradékot jelenti, amit f-nek m-mel való maradékos osztásakor kapunk. Minden ilyen feladatban az első lépés: írd fel, mivel helyettesíthető m főtagja.

6/1bemelegítő

Legyen f = x2 + 1 ∈ ℝ[x]. Számolja ki: a) x2 mod f; b) x3 + x + 1 mod f; c) x4 mod f!

Megoldás

x2 + 1 ≡ 0, vagyis x2 ≡ −1 mod f.

  • a) x2 mod f = −1
  • b) x3 = x · x2 ≡ −x, így x3 + x + 1 ≡ −x + x + 1 → 1
  • c) x4 = (x2)2 ≡ (−1)2 → 1
Ez pontosan a komplex számok számolása: x úgy viselkedik, mint az i (i2 = −1, i4 = 1). Pl. b) i3 + i + 1 = −i + i + 1 = 1.
6/2bemelegítő

Legyen f = x2 + 2, g = 2x2 + x + 1, h = x3 + x + 1 ∈ ℤ3[x]. Számítsa ki modulo x2 + 2x + 2:
a) (f + g)2; b) g · h; c) (f − g)(g − h)(f − h); d) (f − g)3.

Megoldás

Redukciós szabály. x2 + 2x + 2 ≡ 0 → x2 ≡ −2x − 2 = x + 1 (mod 3: −2 = 1). Ebből x3 = x · x2 ≡ x2 + x ≡ 2x + 1.

Először a három polinomot redukáljuk:

  • f = x2 + 2 ≡ (x + 1) + 2 = x + 3 = x
  • g = 2x2 + x + 1 ≡ 2(x + 1) + x + 1 = 3x + 3 = 0 (valóban g = 2(x2 + 2x + 2))
  • h = x3 + x + 1 ≡ (2x + 1) + x + 1 = 3x + 2 = 2

Ezután már csak f ≡ x, g ≡ 0, h ≡ 2 értékekkel számolunk:

  • a) (f + g)2 ≡ x2 ≡ x + 1
  • b) g · h ≡ 0 · 2 = 0
  • c) (x − 0)(0 − 2)(x − 2) = x · 1 · (x + 1) = x2 + x ≡ (x + 1) + x = 2x + 1
  • d) (f − g)3 ≡ x3 ≡ 2x + 1
Részletes magyarázat

Miért szabad előbb redukálni? Ha f ≡ f' és g ≡ g' mod m, akkor f + g ≡ f' + g' és fg ≡ f'g'. Ugyanaz a szabály, mint az egész számoknál: a végeredmény ugyanaz, csak sokkal kisebb polinomokkal kell számolni.

Kerülőút összehasonlításul (a). f + g = 3x2 + x + 3 = x ℤ3-ban, x2-et elosztva x2 + 2x + 2-vel a maradék −2x − 2 = x + 1. Ugyanaz.

c) részletesen. −2 ≡ 1 mod 3, és x − 2 = x + 1. A szorzat x(x + 1) = x2 + x, aminek a foka még 2, tehát még egyszer redukálni kell: x2 + x ≡ (x + 1) + x = 2x + 1.

A végeredmény foka mindig kisebb a modulus fokánál (itt: legfeljebb 1). Ha x2 marad a válaszban, még nem vagy kész.
