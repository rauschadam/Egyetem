Bevezetés

1.

Melyik a C++ egyik alapelve az előadás szerint?

Zero-overhead elv: amit nem használunk, az nem lassítja a programot. C++-ban nincs szemétgyűjtés, és a nyelv multiparadigmás.
2.

Melyik paradigmát nem sorolja az előadás a C++ által támogatottak közé?

A dia szerint a C++ multiparadigmás: procedurális alapok (C), objektum-orientáltság, generikus programozás (STL), metaprogramozás. A logikai paradigma (pl. Prolog) a deklaratív ágba tartozik.
2. előadás · 4 kérdés

Preprocesszor

3.

Mi a fordítás lépéseinek helyes sorrendje?

Előbb a preprocesszor kifejti a direktívákat, aztán a compiler tárgykódot készít, végül a linker összeszerkeszti a futtatható programot.
4.

Mennyi SQUARE( 1 + 2 ) értéke?

#define SQUARE( x ) x * x
Szövegcsere: 1 + 2 * 1 + 2 = 1 + 2 + 2 = 5. Zárójelezve (((x) * (x))) lenne 9.
5.

Melyik eszköz akadályozza meg, hogy egy header kétszer kerüljön be ugyanabba a fordítási egységbe?

Az include guard az első bemásoláskor definiál egy makrót, és ha az már definiált, a tartalmat kihagyja. Ugyanezt teszi a #pragma once.
6.

Melyik fázisban keletkezik az „undefined reference to f(int)” hiba?

A fordító a deklaráció alapján elfogadta a hívást, de a linker egyik tárgykódban sem találja f definícióját.

Lexikális egységek

7.

Mennyi sizeof( h )?

char h[] = "Hello";
A tömb a lezáró '\0'-t is tartalmazza: 5 + 1 = 6. (strlen( h ) lenne 5; egy char* pointer mérete 64 biten 8.)
8.

Mi a feltétel értéke?

int i = -2;
unsigned int j = 3;
if ( i < j ) // ...
Az int unsigned-dá konvertálódik: −2-ből 4294967294 lesz, ami nem kisebb 3-nál. A fordító -Wsign-compare figyelmeztetést ad.
9.

Mi a "Hello" literál típusa?

Konstans karaktertömb, a lezáró nullával együtt 6 elemű.
10.

Melyik azonosítót kerüljük, mert fenntartott?

Az aláhúzással (főleg aláhúzás + nagybetűvel) kezdődő nevek a fordítónak és a szabványkönyvtárnak fenntartottak.
11.

Mit ír ki?

const char a[] = "Hi";
char b[] = "Hi";
std::cout << ( a == b ? "egyenlő" : "különböző" );
Tömböknél az == a címeket hasonlítja össze, és két külön tömb címe különbözik. Tartalmat std::strcmp-pal vagy std::string-gel hasonlítunk.

Típusok és kifejezések

12.

Mennyi 052 értéke?

A vezető 0 oktális (8-as számrendszerbeli) számot jelöl: 5·8 + 2 = 42.
13.

Mi a 12.34f konstans típusa?

Az f utótag float-ot jelent; utótag nélkül double, L-lel long double lenne.
14.

Mennyi sizeof( char )?

A char a nyelv egységtípusa, a sizeof char-okban mér, ezért sizeof( char ) == 1 definíció szerint. A többi típus mérete implementációfüggő.
15.

Mennyi i és j értéke?

int i = 5;
int j = ++i * 2;
A prefix ++i előbb növel, és az új értéket (6) adja; 6 · 2 = 12.
16.

Mennyi d?

double d = (2,5);
A zárójelben a vessző operátor: a 2-t kiértékeli és eldobja, az eredmény az 5.
17.

f() hamisat ad vissza. Meghívódik-e g()?

if ( f() && g() ) // ...
Az && lusta: ha a bal oldal hamis, az eredmény biztosan hamis, a jobb oldal ki sem értékelődik.
18.

Melyik sor nem definiált viselkedés (C++98 szerint)?

Két szekvenciapont között y kétszer módosul. A többi esetben vagy csak egy módosítás van, vagy a vessző operátor / && szekvenciapontot ad.
19.

Mit ír ki?

int x = 3;
if ( x = 0 )
  std::cout << 'A';
else
  std::cout << 'B';
x = 0 értékadás, értéke 0, ami hamis → B. (Utána x is 0.)

Láthatóság és memóriamodell

20.

Mennyi a globális x értéke f() után?

int x = 0;
void f()
{
  int x = 1;
  {
    int x = 2;
    ::x = x;
  }
}
::x a globális x; a jobb oldali x a legbelső (2).
21.

Hol jön létre a new int[ 10 ] által foglalt tömb?

A new a szabad tárból (heap) foglal. Maga a pointerváltozó, amiben a címet tároljuk, lehet a vermen.
22.

Mit jelent globális szinten a static int s;?

Belső szerkesztés (internal linkage): más fájlok nem érik el. Ugyanerre való a névtelen névtér.
23.

Mi a hiba?

int* p = new int[ n ];
// ...
delete p;
new[]-hoz delete [], new-hoz delete tartozik; a keverésük nem definiált viselkedés.
24.

Mi a RAII lényege?

Resource Acquisition Is Initialization: lokális objektum destruktora a blokk elhagyásakor (kivételnél is) automatikusan lefut, így nincs szivárgás.

Élettartam szabályok

25.

Mikor jön létre egy lokális statikus változó?

És a program futásának végén szűnik meg; ezért őrzi meg az értékét a hívások között.
26.

Meddig él egy temporális objektum (pl. h + w két stringre)?

Ezért lógó pointer a const char* p = (h + w).c_str();: a sor végén a temporális megszűnik.
27.

Mi a gond ezzel a függvénnyel?

char* f()
{
  char buf[ 80 ];
  std::cin.getline( buf, 80 );
  return buf;
}
buf automatikus változó, a függvény végén megszűnik; a hívó egy már nem létező tömbre mutató pointert kap.
28.

Mikor szűnik meg egy osztály adattagja?

Az adattag a tartalmazó objektummal együtt jön létre és szűnik meg.
Eredmény: 0 / 0még nincs megválaszolt kérdés
