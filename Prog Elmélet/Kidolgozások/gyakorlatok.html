1. gyakorlat

Állapottér, feladat, program

Célunk olyan módszerek vizsgálata, amelyekkel egy feladathoz garantáltan (matematikai pontossággal igazoltan) helyes program készíthető. Ehhez kell egy matematikai modell a feladat, a program és a megoldás fogalmára.

1. feladatmodellezés

Modellezzük az alábbi feladatot! „Számoljuk ki egy egyenes vonalú egyenletes mozgás sebességét, ha ismert a megtett út hossza és az eltelt idő!”

Megoldás

a) Input-output alapú szemlélet. Az input adatok az út és az idő, értékeik valós számok, együtt \(\R \times \R\). Az output adat a sebesség, \(\R\). A feladat inputhoz outputot rendel: \((120.0,\ 2.0) \to 60.0\), \((270.0,\ 1.5) \to 180.0\), …

\[F : \R \times \R \to \R, \qquad \D_F = \R_0^+ \times \R^+, \qquad F(x, y) ::= x / y \quad (\forall (x, y) \in \D_F)\]

b) Állapot alapú szemlélet. A feladat állapotai az út, idő, sebesség értékeit mutató valós számhármasok, az állapottér \(\R \times \R \times \R\). A feladat csak az \(\R_0^+ \times \R^+ \times \R\) kezdőállapotokban értelmezett: \((120.0, 2.0, *) \to (120.0, 2.0, 60.0)\), \((270.0, 1.5, *) \to (270.0, 1.5, 180.0)\), …

Ha az út, idő, sebesség adatot rendre az \(s\), \(t\), \(v\) címkével azonosítjuk, az állapottér \((s : \R,\ t : \R,\ v : \R)\), egy állapota \(\{s : x,\ t : y,\ v : z\}\), rögzített sorrendnél röviden \((x, y, z)\).

\[F : (s:\R,\ t:\R,\ v:\R) \to (s:\R,\ t:\R,\ v:\R), \qquad \D_F = (s:\R_0^+,\ t:\R^+,\ v:\R), \qquad F(x, y, *) ::= (x,\ y,\ x/y)\]
Adat és kapcsolatfogalom

A feladat adatokból és köztük lévő kapcsolatokból áll.

  • Adat ~ név, pillanatnyi érték, mértékegység, típus (a lehetséges értékek halmaza és a rajtuk végezhető műveletek) → típusérték-halmaz.
  • Kapcsolat ~ reláció.
Input-output alapú szemléletfogalom
  • Input adat ~ ismert, adott értékű adat.
  • Output adat ~ kiszámolandó értékű adat.

A feladat ebben a szemléletben egy leképezés, amely inputhoz outputot rendel.

Állapot alapú szemlélet: állapot, állapottérfogalom

Az input-output szemlélettel nem lehet modellezni, mi történjen a megoldó program input változóival (megőrizzék-e a kezdőértéküket), és azt sem, ha egy változót egyszerre inputként és outputként használunk (pl. helyben rendezés egy tömbben). A programok modellezésénél természetesebb a program különböző állapotairól beszélni.

  • Állapot = az összes (input, output és egyéb) adat egy lehetséges érték-együttese.
  • Állapottér = az összes állapot.

A Descartes-szorzat nem elég pontos az állapottér modellezésére: több azonos típusú adatnál (pl. \(\R \times \R \times \R\)) nem egyértelmű, melyik komponens melyik adat, és két különböző szorzat (\(\N \times \R\) és \(\R \times \N\)) ugyanazt az állapotteret is jelölheti. Ezért az adatokat egyedi címkékkel különböztetjük meg; a címkéket változóknak hívjuk. Egy állapot címkézett értékek halmaza (pl. \(\{s : x,\ t : y,\ v : z\}\)), amely rögzített változósorrend mellett az értékek sorozatával rövidíthető.

1. kvízkvíz

Mi az állapottere az alábbi feladatnak: „Oszt-e egy adott természetes szám egy másik adott természetes számot?” Adjuk meg a feladat egy lehetséges kezdő- és célállapot-párját is!

Megoldás
Saját megoldás (a lapon nincs) Két természetes szám input, a válasz logikai érték: \(A = (x : \N,\ y : \N,\ l : \LL)\), ahol \(l\) azt mondja meg, hogy \(x \mid y\) teljesül-e. Kezdő–cél pár például: \((3, 6, *) \to (3, 6, \igaz)\), vagy \((4, 6, *) \to (4, 6, \hamis)\).
2. feladatmodellezés

Modellezzük az alábbi feladatot! „Adjuk meg egy természetes szám egy természetes osztóját!”

Megoldás

\(A = (n : \N,\ d : \N)\), \(\D_F = A\). Például a \((6, *)\) kezdőállapothoz több célállapot is jó: \((6,1)\), \((6,2)\), \((6,3)\), \((6,6)\).

\[F \subseteq A \times A, \qquad F(x, y) = \{ (u, v) \in A \mid u = x \wedge v \mid x \} \quad (\forall (x, y) \in \D_F), \qquad \text{egyszerűbben: } F(x, *) = \{ (u, v) \mid u = x \wedge v \mid x \}\]

Ha az inputot nem kell megőrizni: \(F(x, *) = \{ (*, v) \mid v \mid x \}\).

Feladatfogalom

A feladat egy nem-determinisztikus leképezés az állapottérből az állapottérbe, azaz egy homogén binér reláció: \(F \subseteq A \times A\).

Az input adatok megőrzésefogalom

A feladat célállapotának nem muszáj megőriznie az input adatok kezdőértékeit. Ez általában a megoldó programon múlik, kivéve, ha a feladat kifejezetten előírja az input adatok megőrzését. Formálisan különbözik a feladat leírása, ha nem kell megőrizni az inputot: ilyenkor még nem-determinisztikusabb.

2. kvízkvíz

Modellezzük az alábbi feladatot: „Adott két egész típusú változó. Cseréljük ki az értékeiket!”

Megoldás
Saját megoldás (a lapon nincs) \(A = (x : \Z,\ y : \Z)\), \(\D_F = A\), és \(F(a, b) = \{ (b, a) \}\) minden \((a, b) \in A\) esetén. Ez determinisztikus feladat; itt az input változók egyben output változók is (ezt az input-output szemlélet nem tudná leírni).

Programfogalom

A program olyan leképezés, amely bármelyik kiinduló állapothoz megadja az abból induló végrehajtásokat, azaz állapotsorozatokat.

A végrehajtások tulajdonságaifogalom
  • végesek (normálisak vagy hibásak), vagy végtelen hosszúak;
  • minden állapotból indul legalább egy;
  • egy állapotból több végrehajtás is indulhat;
  • az első állapotuk mindig a kiinduló állapot.

\(n \neq 0\)

4. feladatsegédváltozó

Adjuk meg az alábbi program néhány végrehajtását! \(A = (x : \Z,\ y : \Z,\ z : \Z)\). (C++-ban: void swap(int &x, int &y) { int z = x; x = y; y = z; })

\(z := x\)
\(x := y\)
\(y := z\)
Megoldás

Legyen megállapodás szerint az alap-állapottér \(A = (x : \Z,\ y : \Z)\), így \(z : \Z\) segédváltozó. Az \(\{x : -4,\ y : 8\}\) állapotból:

\[\{x{:}-4, y{:}8\} \to \langle \{x{:}-4, y{:}8\},\ \{x{:}-4, y{:}8, z{:}-4\},\ \{x{:}8, y{:}8, z{:}-4\},\ \{x{:}8, y{:}-4, z{:}-4\},\ \{x{:}8, y{:}-4\} \rangle\]
Alap-állapottér, segédváltozófogalom

Önmagában egy programnak nincsenek input és output változói, csak változói. Csak a megoldandó feladat dönti el, mely változóknak kell kezdőértéket adni a program indulása előtt, és melyeket kell kiolvasni a leállása után; ezek az input és output változók alkotják a program egy lehetséges alap-állapotterét.

A többi változó segédváltozó: kezdetben még nem létezik, és legkésőbb a program leállásával megszűnik.

A végrehajtások további tulajdonságaifogalom
  • állapotaik vagy az alap-állapottérhez, vagy annak segédváltozókkal kiegészített állapotteréhez tartoznak;
  • mindig alap-állapottérbeli állapotból indulnak;
  • ha végesek és nem hibásak, alap-állapottérbeli állapotban állnak meg;
  • a segédváltozók keletkezését és megszűnését nem kell önálló állapotváltozásként feltüntetni.

Az állapottér, a feladat és a program mellé bejön a programfüggvény és a megoldás fogalma.

1. feladatvégrehajtások

Milyen végrehajtásai vannak az alábbi programnak a 14, a 10, a 6, a 0 és a −3 állapotokból indulva? \(A = (x : H)\), \(H = \{ a \in \Z \mid a \geq -5 \}\).

\(x \neq 10\)
\(x := x + \sgn(x)\)
Megoldás

Emlékeztető: \(\sgn(2) = \sgn(1) = 1\), \(\sgn(0) = 0\), \(\sgn(-1) = -1\).

  • \(14 \to \sq{14, 15, 16, \dots}\) (végtelen)

2. feladatvégrehajtások

Milyen végrehajtásai vannak az alábbi programnak a \((0,0)\), az \((1,1)\), a \((2,2)\) és az \((5,5)\) állapotokból indulva? \(A = (n : \N,\ d : \N)\).

  • \((1,1) \to \sq{(1,1), (1,2), (1,3), (1,4), \dots}\) (végtelen: 1-nek nincs 1-nél nagyobb osztója)

3. feladatprogramfüggvény

Adjuk meg az 1. feladat \(S\) programjának programfüggvényeit (\(p(S)\) és \(\tilde p(S)\))! \(A = (x : H)\), \(H = \{ a \in \Z \mid a \geq -5 \}\), \(S\): ciklus \(x \neq 10\) mellett \(x := x + \sgn(x)\).

Megoldás
\[p(S) \subseteq A \times A, \qquad \D_{p(S)} = \{1, \dots, 10\}, \qquad p(S)(a) = \{10\} \ \ (a \in \{1, \dots, 10\})\] \[\tilde p(S) \subseteq A \times (A \cup \{\fail\}), \qquad \D_{\tilde p(S)} = \{-5, \dots, -1\} \cup \{1, \dots, 10\}\] \[\tilde p(S)(a) = \begin{cases} \{\fail\}, & a \in [-5..-1] \\ \{10\}, & a \in [1..10] \end{cases}\]

A 0 és a 10-nél nagyobb számok egyikben sincsenek benne, mert onnan csak végtelen végrehajtás indul.

1. kvízkvíz

Adjuk meg az alábbi \(S\) program programfüggvényeit (\(p(S)\) és \(\tilde p(S)\))! \(A = \{1, 2, 3\}\),

\[S = \{\ 1 \to \sq{1, 2, 3, 1},\ 1 \to \sq{1, 2},\ \ 2 \to \sq{2, 3},\ 2 \to \sq{2, 2, 2, \dots},\ \ 3 \to \sq{3, 2, 1},\ 3 \to \sq{3, 1, \fail}\ \}\]
Megoldás

\(\D_{p(S)} = \{1\}\), \(p(S)(1) = \{1, 2\}\). (2-ből van végtelen, 3-ból van hibás végrehajtás.)

\(\D_{\tilde p(S)} = \{1, 2, 3\}\), \(\tilde p(S)(1) = \{1, 2\}\), \(\tilde p(S)(2) = \{3\}\), \(\tilde p(S)(3) = \{1, \fail\}\).

Programfüggvényfogalom

A programfüggvény \(p(S)\) megmondja, hogy a program mely állapotokból indulva terminál biztosan, és ilyenkor hol áll meg.

Gyenge programfüggvényfogalom

A gyenge programfüggvény \(\tilde p(S)\) megmondja, hogy a program mely állapotokból indulva állhat le, és hol (a \(\fail\) is lehet „hely”).

Helyesség (megoldás)fogalom

A program a feladat kezdőállapotaiból elindulva a kezdőállapothoz tartozó valamelyik célállapotban terminál.

Formálisan: \(S\) megoldja \(F\)-et, ha 1. \(\D_F \subseteq \D_{p(S)}\) és 2. \(\forall a \in \D_F : p(S)(a) \subseteq F(a)\).

Gyenge helyességfogalom

A program a feladat kezdőállapotaiból elindulva képes megállni, és ha megáll, akkor ezt a kezdőállapothoz tartozó valamelyik célállapotban teszi.

3. kvízkvíz

Ha \(S\) program megoldja az \(F\) feladatot, akkor igazak-e a következő állítások?

  1. Ha \(F\) nem determinisztikus, akkor \(S\) sem determinisztikus. (Nem-determinisztikus feladatot csak nem-determinisztikus program oldhat meg?)

Megoldás: ellenpéldák és bizonyítások

Megoldás definíciója: \(S\) megoldja \(F\)-et, ha 1. \(\D_F \subseteq \D_{p(S)}\) és 2. \(\forall a \in \D_F : p(S)(a) \subseteq F(a)\). „Igaz-e?” kérdésnél: ha nem, egy ellenpélda kell; ha igen, általános bizonyítás.

1. feladatmegoldás

Megoldja-e az \(S\) program az \(F\) feladatot? \(A = \{1, 2, 3\}\),

\[S = \{\ 1 \to \sq{1, 2, 3, 1},\ \ 2 \to \sq{2, 3},\ 2 \to \sq{2, 2, 2, \dots},\ \ 3 \to \sq{3, 2, 1}\ \}, \qquad F = \{ (1,1), (1,3), (3,1) \}\]
Megoldás
  1. \(\{1, 3\} = \D_F \subseteq \D_{p(S)} = \{1, 3\}\) ✓
  2. \(\{1\} = p(S)(1) \subseteq F(1) = \{1, 3\}\) ✓,   \(\{1\} = p(S)(3) \subseteq F(3) = \{1\}\) ✓

Megoldja.

2. feladatmegoldás

Megoldja-e az \(S\) program az \(F\) feladatot? \(A = \{1, 2, 3\}\),

\[S = \{\ 1 \to \sq{1, 2, 3, 1},\ \ 2 \to \sq{2, 3},\ \ 3 \to \sq{3, 2, 1},\ 3 \to \sq{3, 1, \fail}\ \}, \qquad F = \{ (1,1), (1,3), (2,3), (3,1) \}\]
Megoldás
Saját megoldás (a lapon és a jegyzetben nincs) \(\D_F = \{1, 2, 3\}\), de a 3-ból van \(\fail\)-re végződő végrehajtás, így \(\D_{p(S)} = \{1, 2\}\). Az 1. feltétel sérül: \(\D_F \not\subseteq \D_{p(S)}\) ⇒ nem oldja meg.
3. feladatigaz-e?

Legyen \(A\) tetszőleges állapottér, \(S\) egy program, \(F\) egy feladat úgy, hogy \(S\) megoldja \(F\)-et. Igazak-e a következők?

  1. Ha \(F\) nem determinisztikus, akkor \(S\) sem az.
  2. Ha \(F\) determinisztikus, akkor \(S\) is az.
  3. Ha \(S\) nem determinisztikus, akkor \(p(S)\) sem az.
  4. Ha \(p(S)\) nem determinisztikus, akkor \(F\) sem az.
  5. Ha \(F\) determinisztikus, akkor \(p(S)\) is az.
  6. Ha \(F\) nem determinisztikus, akkor \(p(S)\) sem az.
Megoldás

Mind a hat hamis. Ellenpéldák (órai jegyzet), mindegyikben \(A = \{1, 2\}\):

  • a) \(F = \{(1,1), (1,2)\}\) (nem determinisztikus), \(S = \{1 \to \sq{1},\ 2 \to \sq{2, \fail}\}\) (determinisztikus), és megoldja: \(\D_F = \{1\} \subseteq \D_{p(S)} = \{1\}\), \(p(S)(1) = \{1\} \subseteq \{1, 2\}\).
  • b) \(F = \{(1,1)\}\), \(S = \{1 \to \sq{1},\ 2 \to \sq{2, \fail},\ 2 \to \sq{2}\}\) (nem determinisztikus: 2-ből két végrehajtás), \(p(S) = \{(1,1)\}\); megoldja.
  • c) Lásd b): \(S\) nem determinisztikus, de \(p(S) = \{(1,1)\}\) determinisztikus.
  • d) \(S = \{1 \to \sq{1},\ 2 \to \sq{2, 1},\ 2 \to \sq{2}\}\), \(p(S) = \{(1,1), (2,1), (2,2)\}\) (nem determinisztikus), \(F = \{(1,1)\}\) (determinisztikus). Megoldja: \(\{1\} = \D_F \subseteq \D_{p(S)} = \{1, 2\}\), \(\{1\} = p(S)(1) \subseteq F(1) = \{1\}\).
  • e) Lásd d): \(F\) determinisztikus, \(p(S)\) mégsem.
  • f) \(F = \{(1,1), (1,2)\}\), \(S = \{1 \to \sq{1},\ 2 \to \sq{2, \fail},\ 2 \to \sq{2}\}\), \(p(S) = \{(1,1)\}\) (determinisztikus). Megoldja: \(\{1\} = \D_F \subseteq \{1\}\), \(\{1\} \subseteq F(1) = \{1, 2\}\).
A kulcsA megoldás csak a \(\D_F\)-beli kezdőállapotokra mond valamit. Ami \(\D_F\)-en kívül történik (pl. 2-ből), az lehet nem-determinisztikus vagy hibás is; és \(p(S)(a) \subseteq F(a)\) megengedi, hogy a program „szűkebben” válasszon, mint a feladat.

Legyen \(A = \{1, 2, 3\}\) és \(F = \{(1,1), (1,2), (2,3)\}\). Adjunk meg egy \(S\) programot, ami megoldja az \(F\) feladatot!

Megoldás
Saját megoldás (a jegyzetben nincs kitöltve) Például \(S = \{1 \to \sq{1},\ 2 \to \sq{2, 3},\ 3 \to \sq{3}\}\). Ellenőrzés: \(\D_F = \{1, 2\} \subseteq \D_{p(S)} = \{1, 2, 3\}\), \(p(S)(1) = \{1\} \subseteq \{1, 2\}\), \(p(S)(2) = \{3\} \subseteq \{3\}\). A 3-ból bármi lehetne (akár \(\sq{3, \fail}\) is), mert \(3 \notin \D_F\); de minden állapotból kell legalább egy végrehajtás, hogy program legyen.
4. feladatigaz-e?

Legyenek \(S_1\) és \(S_2\) programok az \(A\) állapottér felett úgy, hogy \(S_1 \subseteq S_2\).

  1. Igaz-e, hogy ekkor \(\D_{p(S_1)} \subseteq \D_{p(S_2)}\)?
  2. Igaz-e, hogy ekkor \(\D_{p(S_2)} \subseteq \D_{p(S_1)}\)?
Megoldás

a) Nem. Ellenpélda: \(A = \{a\}\), \(S_1 = \{a \to \sq{a}\}\), \(S_2 = \{a \to \sq{a},\ a \to \sq{a, \fail}\}\). Ekkor \(\D_{p(S_1)} = A\), de \(\D_{p(S_2)} = \emptyset\). (Órán: \(A = \{1,2\}\), \(S_1 = \{1 \to \sq{1}, 2 \to \sq{2}\}\), \(S_2\) ugyanez kiegészítve \(\sq{1, \fail}\)-lel és \(\sq{2, \fail}\)-lel; \(\{1,2\} = \D_{p(S_1)} \not\subseteq \D_{p(S_2)} = \emptyset\).)

b) Igen. Legyen \(a \in \D_{p(S_2)}\); cél: \(a \in \D_{p(S_1)}\).

\[a \in \D_{p(S_2)} \iff S_2(a) \subseteq \overline{A}^{*} \quad /\ \text{programfüggvény def.}\] \[S_1 \subseteq S_2 \Rightarrow S_1(a) \subseteq S_2(a)\ \ (\forall a \in A)\]

A kettőből \(S_1(a) \subseteq \overline{A}^{*}\), ami éppen azt jelenti, hogy \(a \in \D_{p(S_1)}\). (Itt \(\overline{A}^{*}\) a véges, \(\fail\) nélküli sorozatok halmaza.)

5. feladatigaz-e?

Legyen \(A\) egy tetszőleges állapottér, ezen \(S\) és \(S'\) egy-egy program, \(F\) és \(F'\) egy-egy feladat úgy, hogy \(S\) megoldja \(F\)-et. Igazak-e a következők?

  1. Ha \(S \subseteq S'\), akkor \(S'\) is megoldja \(F\)-et.
  2. Ha \(S' \subseteq S\), akkor \(S'\) is megoldja \(F\)-et.
  3. Ha \(F \subseteq F'\), akkor \(S\) megoldja \(F'\)-t is.
Megoldás

a) Nem. \(A = \{a\}\), \(F = \{a \to a\}\), \(S = \{a \to \sq{a}\}\), \(S' = \{a \to \sq{a},\ a \to \sq{a, \fail}\}\); \(\D_{p(S')} = \emptyset\), így \(\D_F \not\subseteq \D_{p(S')}\). (Órán végtelen végrehajtással: \(A = \{1\}\), \(F = \{(1,1)\}\), \(S' = \{1 \to \sq{1},\ 1 \to \sq{1, 1, 1, \dots}\}\), \(\{1\} = \D_F \not\subseteq \D_{p(S')} = \emptyset\).)

b) Igen.

  • Tény: \(\D_F \subseteq \D_{p(S)}\) és \(\forall a \in \D_F : p(S)(a) \subseteq F(a)\) (mert \(S\) megoldja \(F\)-et).
  • Cél: \(\D_F \subseteq \D_{p(S')}\) és \(\forall a \in \D_F : p(S')(a) \subseteq F(a)\) (a megoldás definíciója).
  • \(\D_F \subseteq \D_{p(S)} \subseteq \D_{p(S')}\), mert \(S' \subseteq S\) miatt a 4. feladat b) része szerint \(\D_{p(S)} \subseteq \D_{p(S')}\).
  • \(\forall a \in \D_F : p(S')(a) \subseteq p(S)(a) \subseteq F(a)\). Az első tartalmazás: legyen \(b \in p(S')(a)\). Ekkor \(\exists \alpha \in S'(a) : \alpha_{|\alpha|} = b\) (programfüggvény def.); \(S' \subseteq S \Rightarrow S'(a) \subseteq S(a)\), tehát \(\exists \alpha \in S(a) : \alpha_{|\alpha|} = b\), azaz \(b \in p(S)(a)\).

c) Nem. \(A = \{a\}\), \(F = \emptyset\), \(F' = \{a \to a\}\), \(S = \{a \to \sq{a, \fail}\}\). Az üres feladatot minden program megoldja, \(F'\)-t viszont \(S\) nem.

És ha még \(\D_F = \D_{F'}\) is fennáll? Akkor igen:

  • Tény: \(\D_F \subseteq \D_{p(S)}\), \(\forall a \in \D_F : p(S)(a) \subseteq F(a)\) (mert \(S\) megoldja \(F\)-et); továbbá \(\D_F = \D_{F'}\) és \(\forall a \in \D_F : F(a) \subseteq F'(a)\) (mert \(F \subseteq F'\)).
  • Cél: \(\D_{F'} \subseteq \D_{p(S)}\): \(\D_{F'} = \D_F \subseteq \D_{p(S)}\) ✓; és \(\forall a \in \D_{F'} : p(S)(a) \subseteq F(a) \subseteq F'(a)\) ✓.

Logikai függvények rövid jelölésefogalom

Legyen \(A = (x : \N,\ y : \N)\) és \(R : A \to \LL\), ahol \(\forall a \in A : R(a) = (2 \cdot x(a) + y(a) \geq 5)\) (vagy \(R(\{x{:}m, y{:}n\}) = R((m, n)) = (2m + n \geq 5)\)). Ezt röviden \(R = (2x + y \geq 5)\) alakban írjuk.

Ez a lambda-kalkulus szerinti jelölés egyszerűsítése: \(R = \lambda x.\lambda y.(2x + y \geq 5)\). Kiértékelése \(x\) és/vagy \(y\) behelyettesítésével: \(\lambda x.\lambda y.(2x+y \geq 5)\ 8\ 4 = (2x+y \geq 5)^{x, y \leftarrow 8, 4} = (2 \cdot 8 + 4 \geq 5) = \igaz\), illetve \(\lambda x.(2x+y \geq 5)\ (x - y) = (2x+y \geq 5)^{x \leftarrow x - y} = (2(x-y) + y \geq 5) = (2x - y \geq 5)\).

Paramétertér (régi órai jegyzet)fogalom

Legyen \(F \subseteq A \times A\) feladat. \(F\)-nek \(B\) egy paramétertere, ha \(\exists F_1 \subseteq A \times B\) és \(\exists F_2 \subseteq B \times A\), hogy \(F = F_2 \circ F_1\). A specifikáció tétele (régi órai jegyzet)fogalom

Legyen \(F \subseteq A \times A\) feladat, \(B\) az \(F\) egy paramétertere (\(F = F_2 \circ F_1\)), és \(b \in B\) tetszőleges paraméter, amihez \([Q_b] ::= F_1^{(-1)}(b)\) és \([R_b] ::= F_2(b)\). Ekkor ha \(\forall b \in B : Q_b \Rightarrow \lf(S, R_b)\), akkor az \(S\) program megoldja az \(F\) feladatot.

Az esetek döntő többségében a paramétertér az állapottér bemenő adatkomponenseinek altere; ilyenkor \(F_1 : A \to B\) egy vetítés.

4. feladatspecifikáció

Hol veszi fel az \([m..n]\) intervallumban az \(f : \Z \to \Z\) függvény az utolsó pozitív értékét?

Megoldás

1. változat (az \(f\) is az állapottér része):

\[A = (m : \Z,\ n : \Z,\ f : \Z \to \Z,\ l : \LL,\ ind : \Z), \quad B = (m' : \Z,\ n' : \Z,\ f' : \Z \to \Z), \quad Q = (m = m' \wedge n = n' \wedge f = f')\] \[R = \big(l = (\exists i \in [m'..n'] : f'(i) > 0) \wedge l \to (f'(ind) > 0 \wedge \forall i \in [ind+1..n'] : f'(i) \leq 0)\big)\]

2. változat (\(f\) rögzített függvény, nem állapotkomponens):

\[A = (m : \Z,\ n : \Z,\ l : \LL,\ ind : \Z), \quad B = (m' : \Z,\ n' : \Z), \quad Q = (m = m' \wedge n = n')\] \[R = \big(Q \wedge l = (\exists i \in [m..n] : f(i) > 0) \wedge l \to (f(ind) > 0 \wedge \forall i \in [ind+1..n] : f(i) \leq 0)\big)\]
Az \(l\) szerepeLehet, hogy nincs pozitív érték; ezt az \(l\) logikai változó jelzi, és csak ha \(l\) igaz, akkor kell \(ind\)-nek értelmes helynek lennie.
1. kvízkvíz

Határozzuk meg az \(f : \Z \to \Z\) függvény maximumát az \([m..n]\) intervallum felett.

Megoldás
\[A = (m : \Z,\ n : \Z,\ l : \LL,\ max : \Z), \quad B = (m' : \Z,\ n' : \Z), \quad Q = (m = m' \wedge n = n' \wedge m' \leq n')\] \[R = \big(max = \mathrm{MAX}_{i = m'..n'}\{ f(i) \}\big) = \big(\exists ind \in [m'..n'] : max = f(ind) \wedge \forall i \in [m'..n'] : f(i) \leq max\big)\]
MegjegyzésA lapon \(B = (m : \Z,\ n : \Z)\) szerepel; a paraméterváltozók helyesen \(m'\) és \(n'\). Az \(l\) változó itt nem kell (az \(m' \leq n'\) előfeltétel miatt mindig van maximum).
5. feladatspecifikáció tömbre

Adott az \(x\) egész számokat tartalmazó tömb. Módosítsuk a tömb elemeit úgy, hogy minden eleme a tömb első \(i\) darab eredeti elemének összege legyen.

Megoldás
\[A = (x : \Z^n), \quad B = (x' : \Z^n), \quad Q = (x = x')\] \[R = \Big(\forall i \in [1..n] : x[i] = \sum_{k=1}^{i} x'[k]\Big) = \big(x[1] = x'[1] \wedge \forall i \in [2..n] : x[i] = x[i-1] + x'[i]\big)\]
6. feladatspecifikáció tömbre

Rendezzük növekvő sorba egy egész számokat tartalmazó tömb elemeit.

Megoldás
\[A = (x : \Z^n), \quad B = (x' : \Z^n), \quad Q = (x = x'), \quad R = \big(x \in \perm(x') \wedge \sorted(x)\big)\] \[\perm(x) = \{ s \in \Z^n \mid \exists \varphi : [1..n] \to [1..n] \text{ bijekció} : \forall i \in [1..n] : s[i] = x[\varphi(i)] \}, \qquad \sorted(x) = \forall i \in [2..n] : x[i-1] \leq x[i]\]
2. kvízkvíz

Növeljük meg 1-gyel az \(x\) egész számokat tartalmazó tömb páros elemeit.

Megoldás
\[A = (x : \Z^n), \quad B = (x' : \Z^n), \quad Q = (x = x')\] \[R = \big(\forall i \in [1..n] : (x'[i] \text{ páros} \to x[i] = x'[i] + 1) \wedge (\forall i \in [1..n] : (x'[i] \text{ páratlan} \to x[i] = x'[i]))\big)\]
7. feladatspecifikáció

Adjunk meg egy 10000-nél nagyobb prímszámot.

Megoldás
\[A = (p : \Z), \quad B = \{\sigma\} \ \ (\text{nullatér: egyetlen eleme az origó}), \quad Q = (\igaz), \quad R = (\prim(p) \wedge p > 10000)\]

Ha a feladat \(\D_F = A\), \(F(a) = \{ n \mid \prim(n) \wedge n > 10000 \}\), akkor \(B = \{\sigma\}\), \(\D_{F_1} = A\), \(F_1(a) = \{\sigma\}\), \(\D_{F_2} = B\), \(F_2(\sigma) = \{ n \mid \prim(n) \wedge n > 10000 \}\).

Az elő- és utófeltétel \(\forall b \in B\), azaz egyedül \(\sigma\)-ra: \([Q_\sigma] = F_1^{(-1)}(\sigma) = A\), tehát \(Q_\sigma = \igaz\); \([R_\sigma] = F_2(\sigma) = \{ n \mid \prim(n) \wedge n > 10000 \}\), tehát \(R_\sigma = (\prim(p) \wedge p > 10000)\).

Nincs inputHa a feladatnak nincs bemenő adata, a paramétertér egyelemű (nullatér), és az előfeltétel egyszerűen \(\igaz\).
